# 控制台配置

本插件的所有设置都在 Koishi 控制台里改。这份文档按控制台里的分组，一项一项说明：填什么、默认是什么、有什么用、举例、常见的错。

> 下文的「联盟市场A」「XX-1」「1000000000001」都是编造的例子，换成你们自己的。Jita、Amarr、Perimeter 这些是游戏里公开的名字。
> 文中的「12345」端口只是举例，换成你自己浏览器地址栏里的端口。

## 打开配置页、保存

1. 在浏览器里打开 Koishi 控制台（你平时用的地址，例如经 SSH 隧道打开的 `http://127.0.0.1:12345`）。
2. 点左边的「插件配置」。
3. 在插件列表里点 **eve-market**。
4. 右边就是本插件的配置页：
   - 最上面是一段说明，第一行是「打开 EVE 授权页面」（联盟建筑市场用，见 [EVE授权.md](EVE授权.md)）。
   - 下面按分组排列：基本、显示、权限、市场、物品别名、查价、批量查价、运费、查价告示、EVE 授权、图片与截图、截图、Janice 估价、KB 人物卡、高级。「高级」默认是折叠的，点 `advanced` 那一行右边的「展开以编辑」按钮才能看到里面的设置。
5. 改完以后保存，见下一段。

### 怎么保存

配置页的右上角**没有写着「保存」两个字的按钮**，是一排小图标。鼠标移到图标上，会显示它的名字：

| 插件现在 | 右上角的图标 | 保存用哪一个 |
|---|---|---|
| 启用着（平时都是这样） | 方块「停用插件」、**勾号「重载配置」**，后面还有重命名、删除等 | 点勾号「**重载配置**」。它就是保存：把改动写进配置，再重载本插件一次 |
| 停用着 | 三角「启用插件」、**软盘「保存配置」** | 只保存不启用：点软盘「保存配置」。要启用：点三角「启用插件」 |

- 也可以直接按键盘上的 **Ctrl+S**（苹果电脑上是 Command+S），和点「重载配置」（或「保存配置」）一样。
- 「重载配置」不会丢掉你的改动，放心点。
- 下文和其他文档里说「保存」，都是指这一步。

保存以后：

- 本插件自己重载一次，几秒钟。这几秒里发的命令可能没有回应，过一会儿再发就好。
- **只重载本插件**，别的插件不受影响：LLBot、dcqq-bridge 的转发照常。（安装、升级、卸载插件才会让整个 Koishi 重启。）
- 已经下载的物品数据、ESI 的缓存、建筑市场的订单都还在，不用重新下载。

控制台上的样子：

- 每一项上面的英文是字段名，例如 `general.requireAt`（前面的 `general.` 是浅色的字），下面是中文说明。本文表格的第一列就是字段名，方便对照。
- 「市场」「授权群」这类是**表格**：一行一条，点这张表格标题右边的「**添加行**」加一行（新的一行加在最下面）；每一行最右边有上移、下移和删除（垃圾桶图标）三个小按钮。大多数表格每行有一个「启用」开关，关掉 = 这一行先不用，不会报错。
- 「管理员」这种一项一个值的**列表**，点它标题右边的「**添加项目**」加一项。
- 开关点一下切换；有固定选项的（例如「类型」）是下拉菜单。
- 每一项右边都有一个「…」按钮。改乱了想回到默认值：点「…」→「**恢复默认值**」，再保存。
- 建议一律在控制台里改，不要直接改 `koishi.yml` 文件。

## 写错了怎么办

写错的地方只影响它自己：写错的**那一行**被跳过，别的行、别的设置照常，插件照常加载。

去两个地方看哪里写错了：

1. **Koishi 日志**：控制台左边的「日志」。每次保存以后，每个问题写一行黄色的警告，例如：

   ```
   配置问题：市场第 6 行「位置」不是数字（NPC 空间站填空间站 ID），已跳过
   ```

2. **「市场状态」**：管理员私聊机器人（或者在授权群里 @机器人）发 `市场状态`，卡片下部有一行「配置问题」（在最后一行「命令冲突」的上面）。没有问题时写「配置问题：无」；有好几条时列出前 8 条，再多的写「另有 N 条，详见 Koishi 日志」。

看懂提示：

| 提示里的说法 | 意思 |
|---|---|
| 「市场第 6 行」 | 「市场」表格里从上往下数第 6 行。关掉「启用」的行也算在行数里 |
| 「已跳过」「这一行不生效」 | 这一行整行没有用上。改好再保存 |
| 「已忽略」「这一行的不生效」 | 这一行的某一部分（例如其中一个别名、一个网址）没有用上，其他照常 |
| 「已改用默认值」「已按 4 处理」 | 数字或选项写得不对，插件先用默认值或最接近的允许值。改好再保存 |
| 「有写错的字段（例如类型、启用写成了别的值），已跳过」 | 一般只在直接改 `koishi.yml` 时出现。在控制台里重新选一下这一行的下拉菜单和开关 |

- 有些问题要等物品数据加载好才查得出来，例如空间站 ID 不存在、星系名写错、别名指向的物品找不到。这些在保存后几秒内补写进日志；每周数据更新以后也会再查一遍。
- 「市场状态」只回应管理员，见下面「权限」一节。

## 基本

| 字段 | 默认 | 说明 |
|---|---|---|
| `general.requireAt` | 开 | 群里只处理 @机器人 的消息。私聊不受影响 |
| `general.allowSandbox` | 关 | 测试用：也在 Koishi 控制台的「沙盒」里回复（纯文字） |
| `general.qqWatchdog` | 开 | 官方机器人看门狗：机器人连续 10 分钟不在线时，自动重启 adapter-qq |

- `requireAt`：保持打开。QQ 群主打开机器人的「接收群内全部消息」以后，机器人能看到群里所有消息；这个开关保证插件只回答 @ 它的消息，不会和群里别的机器人抢着回复。
- `allowSandbox`：QQ 机器人还没接好时，用控制台的「沙盒」试命令，做法见 [测试步骤.md](测试步骤.md) 的 A 部分。**测完关掉。**
- `qqWatchdog`：保持打开。adapter-qq 断网恢复以后，有时会一直拿过期的令牌去连（日志每分钟报「AccessToken无效或过期」），自己好不了，以前只能在控制台把 adapter-qq 停用再启用。打开以后插件替你做这件事：机器人连续 10 分钟不在线就重启 adapter-qq（和停用再启用一样），两次至少隔 30 分钟。重启会写进日志，管理员发「市场状态」，「官方机器人」一行能看到重启过几次。它只重启 adapter-qq，不碰 LLBot 和转发。
- 不管这几个开关怎么设，插件都只在 QQ 官方机器人上回复（打开 `allowSandbox` 时再加上沙盒），不会在 LLBot 等 OneBot 机器人上回复。

## 显示

管价格怎么写、要不要按钮。默认值一般不用改；「样式自检」发现 QQ 上显示不对时再改。

| 字段 | 默认 | 可选 | 说明 |
|---|---|---|---|
| `display.output` | Markdown 卡片 | Markdown 卡片 / 纯文字 | QQ 上发 Markdown 卡片；QQ 拒收时自动改发纯文字。选「纯文字」就一律发纯文字 |
| `display.numberStyle` | 灰底等宽 | 灰底等宽 / 加粗 / 普通 | 卡片里完整价格的样式 |
| `display.priceDisplayMode` | `875,700,000 ISK（875.70M）` | 完整加简写 / 只要完整（`875,700,000 ISK`）/ 只要简写（`875.70M`） | 主要金额的写法：查价的单价和合计，批量查价的合计和运费，工业的成本和利润 |
| `display.listPriceDisplayMode` | 只用简写 | 只用简写 / 和上一项相同 | 清单里每一行的价格：批量查价的明细、搜索结果、植入体套装。只用简写时消息不会太长 |
| `display.compactDecimals` | 2 | 0–4 | 简写保留几位小数：2 是 `875.70M`，0 是 `876M` |
| `display.thousandSeparator` | 开 | | 完整价格加千位分隔符：开是 `875,700,000`，关是 `875700000` |
| `display.showCurrency` | 开 | | 完整价格后面带「ISK」 |
| `display.clickable` | 带按钮 | 带按钮 / 不带 | 消息下面带可以点的按钮；选「不带」时只写编号和完整命令 |

常见情况：

- 卡片里价格两边多出反引号「`」，或者灰底显示得很怪：把 `numberStyle` 改成「加粗」或「普通」。
- 按钮点了没反应，或者带按钮的消息发不出去：先把 `clickable` 改成「不带」，再告诉开发者。
- `compactDecimals` 填了 0–4 以外的数，例如 6：日志写「显示：「简写的小数位数」应该在 0–4 之间，已按 4 处理」。

## 权限

决定谁是管理员、哪些群能看到联盟的价格。

### 先拿到 ID：「本群ID」

QQ 官方机器人看到的群和人，ID 都是一长串字母和数字，**不是群号，也不是 QQ 号**。用「本群ID」命令查看：

1. 在群里 @机器人 发 `本群ID`。
2. 机器人回 3 条消息：第 1 条是说明，第 2 条是**本群 ID**，第 3 条是**你的 ID**。长按就能复制。
3. 第 1 条里写着「本群现在：未授权」或「本群现在：已授权」。
4. 私聊机器人发 `本群ID`：回 2 条，第 2 条是你在私聊里的 ID。

第 1 条说明里有一句「管理员一栏填：qq: 加上你的 ID」（私聊里是「qq: 加上下一条的 ID」）。意思是：管理员一栏里可以在 ID 前面加上 `qq:`，也可以不加，两种写法一样。**不要把「qq: 加上」这几个字抄进去**，只抄 ID 本身。

- 同一个人在不同群里、在私聊里的 ID **可能不一样**（待实测）。所以管理员一栏：**群里拿到的 ID 和私聊里拿到的 ID 都加进去**，各占一项。还不能私聊机器人时，先只加群里的。
- 如果第 1 条里还有一行「你的跨群 ID」，这个 ID 在所有群和私聊里都一样，也加进去。
- **重新创建 QQ 机器人以后，所有 ID 都会变**，要重新查、重新填。
- 在控制台沙盒里查到的 ID 前面带着 `sandbox:`，原样照抄。

### 管理员 `access.admins`

默认是空的。一项填一个用户 ID，前面写不写 `qq:` 都行。

管理员能用这几个命令（别人发了没有任何反应，帮助里也看不到）：

| 命令 | 在哪里回应 |
|---|---|
| 市场状态、市场授权 | 只在**私聊**或**授权群**里。在没授权的群里发也没有反应，这是正常的 |
| 样式自检 | 哪个群都行 |

另外：管理员私聊机器人时，按授权群对待（能看到联盟市场）。Koishi 里权限等级 4 以上的账号也算管理员，一般用不到。

怎么加：

1. 在群里 @机器人 发 `本群ID`，长按第 3 条（你的 ID）复制。
2. 控制台 → eve-market →「权限」→ 点 `access.admins` 右边的「添加项目」，在新出现的框里粘贴。
3. 能私聊机器人的话，私聊发 `本群ID`，长按第 2 条复制，再「添加项目」粘贴一次。
4. 保存。
5. 检查：在群里 @机器人 发 `帮助 样式自检`（私聊里直接发）。回复的标题是「**样式自检（管理员）**」就对了；回的是帮助总表（标题「EVE 市场助手」），说明你在这里还不算管理员。

没算上管理员时：多半是填的 ID 和你发命令的地方对不上（例如只填了私聊里拿到的 ID，却在群里发）。在你发命令的地方再发一次 `本群ID`，把那里显示的「你的 ID」也加进去。

注意：在**没授权的群**里，管理员发 `帮助` 也看不到「管理」那一行，发 `市场状态` 也没有反应，这是正常的（见上表）。所以上面用 `帮助 样式自检` 检查，它在哪里都能用。

### 授权群 `access.allowedGroups`

表格，每行：群 ID、备注、启用。默认是空的。

授权群能看到：

- 「谁能看到」是「只在授权群」的市场。联盟建筑市场默认就是这样；
- 「只在授权群」的运费路线和查价告示；
- 管理员可以在这个群里用「市场状态」「市场授权」。

没授权的群照样能查 Jita 等公开市场，只是看不到上面这些，就像它们不存在一样。

怎么加：

1. 在要授权的群里 @机器人 发 `本群ID`，长按第 2 条（本群 ID）复制。
2. 控制台「权限」→ 点 `access.allowedGroups` 右边的「添加行」，在新的一行里填：
   - 群 ID：粘贴；
   - 备注：写个好认的名字，例如「联盟主群」；
   - 启用：打开。
3. 保存。
4. 回到群里再发一次 `本群ID`，第 1 条应该写「本群现在：已授权」。

常见的错：

| 现象或提示 | 原因 | 怎么改 |
|---|---|---|
| 填了以后「本群ID」还是「未授权」 | 填成了第 3 条（你的 ID） | 换成第 2 条 |
| 授权群第 2 行「群 ID」里有空格，已跳过 | 复制时带进了空格或换行 | 重新复制粘贴 |
| 授权群第 2 行「群 ID」为空，已跳过 | 这一行没填 ID | 填上，或者删掉这一行 |
| 以前好好的，忽然所有群都变成「未授权」 | 重新创建过 QQ 机器人，ID 全变了 | 每个群重新发 `本群ID`，重新填 |

### 授权私聊用户 `access.allowedUsers`

表格，每行：用户 ID、备注、启用。默认是空的。日志里这张表叫「授权私聊用户」。

- 这里的人私聊机器人时，按授权群对待：能看到联盟市场、「只在授权群」的运费和告示。
- 管理员自动算在内，不用重复填。
- 填**私聊里**拿到的 ID（让对方私聊机器人发 `本群ID`，把第 2 条发给你）。

| Amarr | | NPC 空间站 | 60008494 | 不列 | 10 |

### 每一列

| 列 | 填什么 | 新加一行时的默认 |
|---|---|---|
| 名称 | 群友查价时打的名字，卡片上的小标题也是它。不能重复 | 空 |
| 别名 | 其他叫法，多个用逗号分隔（中英文逗号、顿号、分号都行），不区分大小写 | 空 |
| 类型 | NPC 空间站 / 整个星系 / 整个星域 / 玩家建筑 | NPC 空间站 |
| 位置 | 按类型填，见下一节 | 空 |
| 建筑所在星系 | 只用于玩家建筑，见后面 | 空 |
| 启用 | 关掉 = 先不用这一行 | 开 |
| 默认查价 | 自动 / 列出 / 不列：「查价 物品」不写市场时列不列这个市场 | 自动 |
| 排序 | 数字，小的排在前面 | 0 |
| 谁能看到 | 自动 / 所有群 / 只在授权群 | 自动 |
| 授权档案 | 只用于玩家建筑：用哪个 EVE 授权档案。别的类型这一格写什么都不用 | `default` |
| 备注 | 写给自己看，插件不用 | 空 |

### 类型和位置

| 类型 | 位置填什么 | 例子 | 自动加上的别名 |
|---|---|---|---|
| NPC 空间站 | 空间站 ID（纯数字） | `60003760`（Jita 4-4） | 空间站所在星系的中英文名，例如 `Jita`、`吉他` |
| 整个星系 | 星系名（中文或英文）或星系 ID | `Perimeter`、`皮尔米特` 或 `30000144` | 星系的中英文名 |
| 整个星域 | 星域名（中文或英文）或星域 ID | `The Forge`、`伏尔戈` 或 `10000002` | 没有 |
| 玩家建筑 | 建筑 ID（纯数字） | `1000000000001` | 没有 |

- NPC 空间站只算挂在这个空间站里的订单；「整个星系」「整个星域」算整个星系、星域里的订单。
- 有了自动别名，`查价 吉他 乌鸦级` 和 `查价 Jita 4-4 乌鸦级` 是一样的。自动别名和别的市场的名称、手写别名撞了时，自动的那个不用，也不报告。
- 想加别的 NPC 交易中心，最简单的是用「整个星系」，位置填星系名，不用去找空间站 ID。
- 不知道星系的正确写法：发 `翻译 星系名` 看看中英文名。
- 玩家建筑的 ID 在 EVE 授权页面里按名字搜，搜索结果下面直接写着这一行怎么填，见 [EVE授权.md](EVE授权.md) 第 4 步。

### 默认查价

群友发「查价 物品」、不写市场时，列出哪些市场：

- **自动**：玩家建筑列出；基准市场（「查价」分组的 `price.baseMarket`，默认 Jita 4-4）列出；其他不列。基准市场留空时，改成列出第一个公开市场。
- **列出 / 不列**：照你选的。
- 列出的市场按「排序」从小到大排，排序一样时按表格里的先后；最多列 8 个。
- 只列这个群看得到的：没授权的群只会看到公开的那几个。

例：想让 Amarr 也出现在「查价 乌鸦级」的结果里，把 Amarr 那一行的「默认查价」改成「列出」。

### 谁能看到

| 选项 | 意思 |
|---|---|
| 自动 | 玩家建筑 = 只在授权群；其他类型 = 所有群 |
| 所有群 | 任何群都能看到 |
| 只在授权群 | 只有授权群、授权私聊用户和管理员的私聊能看到 |

- 看不到的群里，这个市场就像不存在一样，写它的名字也查不到。
- **把联盟建筑改成「所有群」，联盟的价格就会出现在所有群里**，一般不要这样做。

### 授权档案和建筑所在星系（只用于玩家建筑）

- **授权档案**：写 EVE 授权页面里的档案名，一般就是 `default`。只能用文字、数字、`-` 和 `_`，最多 32 个字。
- **填了授权档案**：「建筑所在星系」可以空着，授权以后插件自己查。填上也行；填错了日志里会提醒，但这一行照常用。
- **授权档案留空** = 不用授权，只读这个建筑公开的订单（从星域订单里找，这个用法还没有实测）。这时**必须**填「建筑所在星系」，否则这一行跳过。
- 「EVE 授权」分组里还没填 Client ID 时，用了授权档案的每一行都会提示「…使用的授权档案 default 还没有授权」。按 [EVE授权.md](EVE授权.md) 做完就好。

### 名称和别名的规则

- 名称不能重复。不区分大小写，`Jita 4-4` 和 `jita 4-4` 算重复。重复的后一行跳过。
- 名称和别名**不能**用下面这些写法，因为它们会和命令的参数混在一起：
  - 价格类型的词：`sell` `出售` `出售价` `卖` `卖价` `卖单` `buy` `收购` `收购价` `买` `买价` `买单` `mid` `中间` `中间价` `中` `split`；
  - `全部` `all` `高级` `材料` `刷新`；
  - 纯数字（会被当成数量）；
  - `95%`、`-5%`、`95折` 这种（会被当成价格调整）；
  - `从81` 这种「从」加数字（会被当成完整清单的页码）；
  - 以 `#` 开头的。
- 一个别名已经是别的市场的名称或别名时，后面那一行的这个别名不生效，日志里会写。

### 例子

**加一个联盟建筑市场**（先按 [EVE授权.md](EVE授权.md) 做好授权）：

| 名称 | 别名 | 类型 | 位置 | 建筑所在星系 | 默认查价 | 谁能看到 | 授权档案 |
|---|---|---|---|---|---|---|---|
| 联盟市场A | 市场A, A市 | 玩家建筑 | 1000000000001 | XX-1 | 自动 | 自动 | default |

保存以后，在授权群里发 `查价 乌鸦级`，会多出「联盟市场A」一节；没授权的群看不到。

**加一个整个星系的市场**：名称 `Perimeter`，类型「整个星系」，位置 `Perimeter`，默认查价「不列」。之后可以发 `查价 Perimeter 乌鸦级`，也可以写 `查价 皮尔米特 乌鸦级`。

**临时不用 Hek**：把 Hek 那一行的「启用」关掉，保存。

## 物品别名

表格，每行：别名、目标物品、启用、备注。默认是空的。

- 给物品加一个叫法。群友写别名，就等于写目标物品。
- 目标物品可以写英文名、中文名，或者 typeID（物品编号，例如 `638` 或 `#638`）。
- 别名不区分大小写，空格也不算：`大 鸟` 和 `大鸟` 算同一个。
- 黑话表（eve-cn-slang 的 `glossary.yaml`）里的叫法会自动接入，不用在这里重复填。这里写的和黑话表冲突时，**以这里为准**。
- 别名不能和另一个物品的正式名称一样（按正式名称查询永远优先）。

例子：

| 别名 | 目标物品 | 备注 |
|---|---|---|
| 大鸟 | Raven | |
| 海军乌鸦 | 乌鸦级海军型 | |

保存以后，`查价 大鸟` 和 `查价 乌鸦级` 一样。

常见的错（提示前面都带着「物品别名第 N 行」）：

| 提示 | 原因 | 怎么改 |
|---|---|---|
| 「别名」为空，已跳过 | 别名没填 | 填上，或删掉这一行 |
| 别名「X」没有写目标物品，已跳过 | 目标没填 | 填上 |
| 别名「X」和第 M 行重复，已跳过 / 和第 M 行的写法相同，已跳过 | 两行的别名一样 | 删掉一行 |
| 别名「X」的目标「Y」找不到对应的物品，这一行不生效 | 目标写错 | 写游戏里的完整名字。可以先发 `查价 Y` 试试能不能查到 |
| 别名「X」的目标「Y」对应多个物品，请改写成 #typeID，这一行不生效 | 这个名字对应好几个物品。例如中文「救赎级」有两个物品（Absolution 和 Salvation） | 改写英文名，例如 `Absolution` |
| 别名「X」和物品「Z」的名字相同，按名字查询优先，这一行不生效 | 别名就是另一个物品的正式名称 | 换个别名 |
| 别名「X」里没有可用的字，已跳过 | 只写了符号 | 换个别名 |

## 查价

| 字段 | 默认 | 说明 |
|---|---|---|
| `price.baseMarket` | `Jita 4-4` | 基准市场 |
| `price.defaultQuantities` | 一行：PLEX，500 | 不写数量时另外给出的合计 |

### 基准市场 `price.baseMarket`

填「市场」表格里的名称或别名。它有这几个用处：

1. 查价卡片上，其他市场的价格后面显示和它比的涨跌。例如 Amarr 出售价后面的「▲4.5%」，表示比 Jita 贵 4.5%；卡片最下面写「▲▼ 与 Jita 4-4 比较」。相差不到 0.1% 时不画。
2. 「走势」「搜索」不写市场时用它。
3. 批量查价的运费只在用它估价时显示（见「运费」一节）。
4. 「默认查价」选「自动」时，它会被列出。
5. 别的设置引用的市场（例如批量查价的默认市场）写错了、或者本群看不到时，改用它。

- 留空：不显示涨跌，也不显示运费；走势、搜索改用第一个能用的公开市场。
- 写了表格里没有的名字：日志写「查价：「基准市场」写的「X」找不到这个市场，改用 Jita 4-4」（改用的是第一个公开市场）。

### 默认数量 `price.defaultQuantities`

表格，每行：物品、数量。默认一行：PLEX，500。

- 查价时没写数量，就按这里的数量另外算一个合计。默认设置下发 `查价 PLEX`，标题里写「×500」，每个价格后面多一个「合计」。
- 自己写了数量（`查价 PLEX*100`）时按写的算。
- 物品的写法和查价一样：英文名、中文名或 typeID，必须只对应一个物品。
- 数量是 1 到 10¹²（一万亿）之间的整数。

常见的错（提示前面都带着「默认数量第 N 行」）：

| 提示 | 怎么改 |
|---|---|
| 「物品」为空，已跳过 | 填上物品，或删掉这一行 |
| X 的数量要是 1 到 10¹² 之间的整数，已跳过 | 改成整数 |
| X 和第 M 行重复，已跳过 | 删掉一行 |
| 「物品」X 找不到对应的物品，这一行不生效 | 写游戏里的完整名字（英文或中文）。可以先发 `查价 X` 试试 |
| 「物品」X 不能在市场上交易，这一行不生效 | 这个东西不能在市场上买卖，删掉这一行 |
| 「物品」X 对应多个物品，请改写成 #typeID，这一行不生效 | 写完整的英文名；中文名对应好几个物品时改写成 `#typeID`。例如中文「救赎级」有两个物品，写 `Absolution` 或 `#22448` |
| 「物品」X 不是一个确定的物品，请写完整的名字或 #typeID，这一行不生效 | 只写了名字的一部分。写完整的名字，或者 `#typeID` |

## 批量查价

| 字段 | 默认 | 说明 |
|---|---|---|
| `appraisal.defaultMarket` | `Jita 4-4` | 「批量查价」不写市场时在哪个市场估价。填市场的名称或别名。本群看不到这个市场时改用基准市场 |
| `appraisal.defaultPriceType` | 出售价 | 出售价 / 中间价 / 收购价 |
| `appraisal.fallbackMarket` | 空 | 回退市场 |

- 这里只是不写时的默认。群友每次都可以在命令里改，例如 `批量查价 Amarr buy -5%`：在 Amarr 按收购价估、再减 5%。
- 例：联盟群里大家主要在联盟市场A 买卖，可以把默认市场改成 `联盟市场A`。没授权的群看不到它，会自动改用 Jita 4-4。注意运费只在用基准市场估价时显示。

**回退市场**：

- 某个物品在选的市场**没有挂单**时，改用回退市场的价格。卡片上这个物品标 †，下面写「† 标记的物品 … 没有价格，已改用 … 出售价」。
- 留空 = 不回退：这些物品写在「没有计入合计」里。
- 整个市场暂时用不了（例如联盟建筑授权异常）时**不会**回退。卡片上直接说明这个市场不可用，清单已经保存，可以点按钮改用别的市场。

常见的错：「默认市场」「回退市场」写了表格里没有的名字，日志写「批量查价：「默认市场」写的「X」找不到这个市场，改用 Jita 4-4」。改成市场表格里的名称或别名。

## 运费

表格 `freight.routes`。默认是空的，空 = 卡片上不显示运费。

| 列 | 填什么 | 默认 |
|---|---|---|
| 名称 | 运到哪里。卡片上显示「运到 名称」 | 空 |
| ISK/m³ | 每立方米多少 ISK | 0 |
| 押金费率 % | 押金的百分之几。填 `1` 就是 1% | 0 |
| 单单最大体积 m³ | 一个合同最多装多少立方米；`0` = 不限 | 0 |
| 谁能看到 | 所有群 / 只在授权群 | 只在授权群 |
| 启用 | | 开 |
| 备注 | 写给自己看 | 空 |

### 什么时候显示

- 只在**用基准市场估价**时显示。默认就是 `批量查价` 不写市场、在 Jita 估价的时候。在 Amarr、联盟市场估价时不显示，因为运费算的是「从 Jita 运过去」。
- 最多显示 2 条：表格里从上往下，本群能看到的前 2 条。
- 「查价」分组的基准市场留空时，运费一律不显示。

### 怎么算

```
运费     = 打包体积 × ISK/m³ + 押金 × 押金费率
押金     = 清单里每样东西的 Jita 出售价 × 数量，全部加起来
到货成本 = 批量查价的合计（加减百分比以后的）+ 运费
```

- 体积按**打包后**的体积算（船按打包体积）。
- 押金一律按基准市场（Jita）的**出售价**算，不管这次估价用的是收购价，还是写了 `-5%`。
- Jita 没有出售价的物品不算进押金，卡片上会写「（N 种物品没有 Jita 4-4 出售价，押金没有算进去）」。
- 总体积超过「单单最大体积」时，卡片上提醒要拆成几单（总体积 ÷ 单单最大体积，有小数就进一）。**运费本身不变**，还是按总体积算。

### 例子

运费表格里一行：名称 `XX-1`，ISK/m³ `800`，押金费率 `1`，单单最大体积 `30000`。

群友粘贴一份清单（不写市场，默认按 Jita 出售价），打包体积 50,328 m³，Jita 出售价合计 379,312,120 ISK：

```
运费     = 50,328 × 800 + 379,312,120 × 1%
         = 40,262,400 + 3,793,121
         = 44,055,521 ISK（约 44.06M）

到货成本 = 379,312,120 + 44,055,521
         = 423,367,641 ISK

拆单     = 50,328 ÷ 30,000 = 1.68 → 2 单
```

卡片上大致是这样一行：

```
🚚 运到 XX-1 约 44,055,521 ISK（44.06M）· 800 ISK/m³ + 押金 1% · 到货成本 423.37M · 超过 30,000 m³，需要拆成 2 单
```

如果群友写的是 `批量查价 -5%`：合计变成 360,346,514 ISK；押金还是按 379,312,120 算，所以运费还是 44,055,521；到货成本 = 360,346,514 + 44,055,521 = 404,402,035 ISK。

### 常见问题

| 现象或提示 | 原因 | 怎么改 |
|---|---|---|
| 卡片上没有运费 | 估价市场不是基准市场；或者这个群没授权、路线是「只在授权群」；或者路线的「启用」关了；或者清单里一个价格都没有 | 逐条检查 |
| 运费第 N 行「名称」X 和第 M 行重复，已跳过 | 两条路线同名 | 改掉一个 |

## 查价告示

表格 `notices.list`。默认是空的。

| 列 | 填什么 | 默认 |
|---|---|---|
| 内容 | 一行字，不超过 80 个字，不能带网址 | 空 |
| 谁能看到 | 所有群 / 只在授权群 | 只在授权群 |
| 截止时间 | 北京时间，写成 `2026-12-31 23:59`；留空 = 一直显示 | 空 |
| 启用 | | 开 |

- 告示附在「查价」「批量查价」结果的最下面，前面带 📢。
- 最多显示 2 条：从上往下数，启用的、没过截止时间的、本群能看到的前 2 条。
- 截止时间也可以写成 `2026/12/31 23:59`；只写日期（`2026-12-31`）= 那天 23:59。过了时间自动不显示，不用手动删。

| 价格仅供参考，以游戏里为准 | 所有群 | |

常见问题（提示前面都带着「查价告示第 N 行」）：

| 现象或提示 | 怎么改 |
|---|---|
| 「内容」超过 80 字，已跳过 | 写短一点 |
| 「内容」里有网址（QQ 群里不允许发网址），已跳过 | 删掉网址和带点的英文写法 |
| 「截止时间」X 看不懂（应该写成 2026-12-31 23:59），已跳过 | 按 `年-月-日 时:分` 写 |
| 写了告示但群里看不到 | 这个群没授权而告示是「只在授权群」；或者已经过了截止时间；或者前面已经有 2 条了 |

## EVE 授权

只有联盟建筑市场需要。完整步骤见 [EVE授权.md](EVE授权.md)，这里只列字段。

| 字段 | 默认 | 说明 |
|---|---|---|
| `sso.clientId` | 空 | EVE 开发者网站上应用的 Client ID |
| `sso.clientSecret` | 空 | 应用的 Secret Key。控制台里显示成密码框。只填在这里，不要发给任何人 |
| `sso.callbackUrl` | `http://127.0.0.1:5140/eve-market/sso/callback` | 回调地址：必须和开发者网站上填的一模一样 |
| `sso.adminKey` | 空 | 授权页面的口令 |

- 回调地址 = 你打开控制台用的地址 + `/eve-market/sso/callback`。例如经 SSH 隧道用 12345 端口打开控制台，就填 `http://127.0.0.1:12345/eve-market/sso/callback`。授权页面「第 1 步」会显示应该填什么，照抄最稳妥。
- 口令：这台电脑上有反向代理、内网穿透或端口转发把 Koishi 的端口开放出去时，**一定要设**；都没有时可以不填。

常见的错：

| 提示 | 怎么改 |

| EVE 授权：填了 Client ID，但还没填 Secret Key（或者反过来） | 两个都填上 |
| EVE 授权：「回调地址」X 不是 http:// 或 https:// 开头的网址，已改用 http://127.0.0.1:5140/eve-market/sso/callback | 照授权页面上显示的那一行重新填 |
| EVE 授权：「回调地址」的路径应该是 /eve-market/sso/callback，现在写的地址授权后回不到插件 | 地址末尾要正好是 `/eve-market/sso/callback` |

## 截图

位置：「图片与截图」下面、「高级」上面。决定「截图」「战报」两个命令和 @机器人 发链接时自动截图能截哪些网站，另有一个击杀链接的开关 `screenshot.killAuto`。

**内置网站**（每个网站一小块，三个设置）：

| 网站 | 启用 | 自动截图 | 最多几张 |
|---|---|---|---|
| `screenshot.br` BR 工具战报（br.evetools.org） | 开 | 开 | 2 |
| `screenshot.warbeacon` Warbeacon 战报（warbeacon.net） | 开 | 开 | 2 |
| `screenshot.janice` Janice 估价结果（janice.e-351.com） | 开 | 开 | 2 |
| `screenshot.dotlan` DOTLAN 星图（evemaps.dotlan.net） | 开 | 开 | 1 |

- 启用：关掉 = 这个网站完全不截（「截图」「战报」和自动截图都不截），「截图」的网站名单里也不再列它。
- 自动截图：关掉 = @机器人 发这个网站的链接时不自动截，要写「截图 网址」才截。
- 最多几张：1–3。每张最多 4000 像素高，所以 2 张约 8000 像素。页面更长时只截前面这一段，最后一张下面写「页面过长，已截取前 N 像素」。私聊里每条消息能发的条数少，实际最多 2 张。
- Warbeacon、Janice、DOTLAN 的网址格式和页面参数还没在生产机上核对过（见 [测试步骤](测试步骤.md) 的 A73–A85）。某个网站认不出或者截得不对，先在这里把它的「启用」或「自动截图」关掉，不用发版。
- 页面怎么等：先打开页面拿到 HTTP 状态码，再最多等几秒让网络安静（页面一直有长连接也不会卡住，到时间照样截），然后点掉同意框、等页面稳定再截（页面高度、文字量连续 1.5 秒不变才算稳定，只有页头的空壳会多等到 3.5 秒；各网站最多等 5–8 秒，到点照样截）。Warbeacon 的内容在页面内部滚动，截图前会把窗口加高到内容装得下。所以网站截图失败时「截图测试」里一般都有 HTTP 状态；只有网站完全连不上才是「没有」。DOTLAN 的 cookie 同意框会自动点「I decline」（拒绝），Warbeacon 的拖放提示框会藏起来。
- 改控制台设置保存后插件会重载，这时正在截的图会直接放弃、不回复，日志里也不记失败；重新发一次命令就行。
- BR 工具的「自动截图」要和上面「图片与截图」里的旧开关 `render.brAuto` 同时开着才自动截。

**击杀链接自动回卡片**（`screenshot.killAuto`，默认开）：

- 开着：@机器人 的消息（私聊里直接发）带 zKill 击杀链接或欧服击杀链接时，自动回「击杀」命令的卡片，不用写命令；卡片下面有「BR 战报」「Warbeacon 战报」两个按钮。
- 关掉：带击杀链接的消息不自动回，要写「击杀 链接或编号」才有卡片；「战报 击杀 编号」「战报 链接」不受这个开关影响。
- 优先级：名单里网站的链接（BR 工具战报等）排在前面，其次是击杀链接，再其次是单独一个物品名。一条消息只处理一次。
- 卡片上两个战报按钮跟着上面的网站设置走：BR 工具或 Warbeacon 的「启用」关掉，对应的按钮就不放；两个都关掉时卡片上写「两个战报网站都在控制台关掉了」。按钮只放「战报 击杀 编号」这样的命令，不带网址。
- 击杀的详情来自 zKill，欧服链接（带校验码的那种）才去问欧服接口；zKill 限流或连不上时回复里会写明，过一两分钟再试。

**自定义网站**（`screenshot.custom`，表格，一行一个，最多 10 行）：

| 列 | 说明 | 默认 |
|---|---|---|
| 名称 | 回复里显示的名字，例如「某某联盟 KB」。不能写成网址的样子 | 必填 |
| 域名 | 只写域名，例如 `kb.example.com`。它下面的子域名也算。粘贴了整个网址也行，会自动只取域名 | 必填 |
| 网址开头 | 可选。只截这个开头的页面，例如 `/kill/`。留空 = 这个域名下的所有页面 | 空 |
| 自动截图 | 关掉 = 要写「截图 网址」才截 | 开 |
| 最多几张 | 1–3 | 1 |

- 自定义网站没有「启用」列：不想用就删掉这一行（或者把域名清空）。
- 自定义网站保留链接里的查询参数（`?` 后面的部分），内置网站都去掉。
- 这些情况这一行会被跳过，Koishi 日志和「市场状态」里写明原因：域名是 IP 地址、`localhost`、没有点的名字（例如 `intranet`）、`.local` `.internal` `.lan` 这类内网后缀、带端口或用户名、内置网站已经有的域名、zKillboard（不支持，以后另做）、nip.io 这类能把任何名字解析到任意地址（包括内网）的域名、github.io 这类公共托管域名本身（要填具体的子域名，例如 `xxx.github.io`）；名称像网址；超过 10 行的部分。
- 最多几张写错时：不是数字就按默认值 1 张算；有小数的四舍五入；不在 1–3 之间的按最近的边界算（0 按 1，9 按 3）。「配置问题」里会有一行，例如「应该在 1–3 之间，已按 3 处理」。

**安全**（不用设置，供参考）：

- 只打开名单里的域名，一律用 https，打开的地址由程序重新拼出来，不是消息里的原文。
- 页面跳到名单以外的域名就放弃（回复「这个链接跳到了别的网站，没有截图。」）；页面里对本机和内网地址的请求一律拦下。
- 回复里不写出链接或域名，只写网站名字。
- 同一时间只截一个外部页面，其他的排队；前面排太多、来不及在回复时限内截完时回复「截图繁忙，请稍后再试。」
- 网站弹出人机验证页（「请稍候」「Just a moment」之类）时回复「这个网站不让自动截图。」，不会去绕过。
- 管理员可以发「截图测试 网址」：不用缓存截一次，并多发一张检查结果（HTTP 状态、打开用时、页面标题、页面高度、截了几张、是不是验证页、拦下的跳转和内网请求个数）。用它核对新网站，结果告诉开发者。

## Janice 估价

位置：「截图」下面、「高级」上面。让群友 @机器人 发 Janice 估价链接（或写「估价 链接」）时，机器人按编号读出这份现成的估价：三个价格、可复制的物品清单、网页截图。**机器人不会把任何清单发给 Janice，只读你们已经在 Janice 网站上做好的估价。**

| 设置 | 默认 | 说明 |
|---|---|---|
| `janice.apiKey` Janice 的 API 密钥 | 空 | 密码框。留空 = 没开通 |
| `janice.who` 谁能用 | 授权群和授权私聊 | 授权群和授权私聊 / 所有人 / 只有管理员；管理员一直能用 |

- 密钥向 Janice 网站申请，只填在这里，不要发给任何人。它**只会出现在发给 Janice 的请求头里**，不会出现在回复、日志、「市场状态」和配置问题里；如果粘贴时带进了空格、换行等不能放进请求头的字符，会自动去掉并在「市场状态」的配置问题里提醒（提醒里不写密钥）。
- 没填密钥：「估价 链接」回复「Janice 估价还没开通（管理员要在控制台填 Janice 的 API 密钥）」，如果截图可用还会附上网页截图；@机器人 单独发 Janice 链接时和以前一样只截图。
- 没有权限的人：「估价」只回一句话；@机器人 发 Janice 链接时只有截图（截图自己的开关照常管）。一条消息里有多个能截的链接时只处理第一个：Janice 链接在前才走估价，别的网站链接（如 BR 战报）在前就只截那个。
- 不限每天次数。读过的估价在内存里放 6 小时（价格创建时就定了），「没有这份估价」记 10 分钟；对 Janice 的请求排队发，每次间隔至少 1 秒。
- 价格直接用 Janice 接口返回的数，和网页一致（接口给的数已经是这份估价设定的比例，插件不会再乘一次），卡片上写「按这份估价设定的 93%」；读不到比例时只在卡片上注明「比例读不到，按 100% 显示」，价格不变。
- 网页截图跟着上面「截图」里 Janice 的设置走：群里「启用」和「自动截图」都开、回复条数够时自动发；否则卡片上放「网页截图」按钮（单聊一律是按钮）；「启用」关掉就既不发图也不放按钮。
- 「市场状态」里有一行 Janice：已开通 / 未开通 / 最近一次异常（密钥被拒绝时标红）。

## KB 人物卡

位置：「Janice 估价」下面、「高级」上面。群友发 `KB 人物英文名`（或 `战绩 …`、人物 ID、zKill 人物链接），机器人回一张报纸头版风格的人物战绩图：大标题、导语、击毁损失、常开的船、常出没的星系、活跃时段、近期大击杀和大损失。全部是公开数据，不需要任何密钥；只有一种样式（新伊甸日报），没有样式设置。

| 设置 | 默认 | 说明 |
|---|---|---|
| `kb.scope` 在哪里可用 | 所有群和私聊 | 所有群和私聊 / 只在授权群和授权私聊 / 关闭；管理员一直能用（关闭时管理员也不能用） |
| `kb.recent` 近期大击杀和作息 | 开 | 开：卡片上多「近期大击杀 / 大损失」和按小时统计的活跃时段，每张卡多查 2 次 zKillboard，慢 2–3 秒；关：出图更快，没有近期大击杀 / 大损失（按小时的活跃时段来自 zKillboard 统计，不受这个开关影响） |
| `kb.auto` 自动识别人物链接 | 开 | @机器人 的消息里带 zKillboard 人物链接时自动回人物卡 |
| `kb.tone` 毒舌程度 | 混合 | 毒舌：标题、导语、锐评、读者来信、运势、广告只用毒舌的句子；温和：只用温和的句子；混合：两种句子混在一起选。同一个人同一天看到的内容固定，隔天换；改了这个设置，新查的卡立刻按新的来（旧的缓存按语气分开存） |
| `kb.hidden` 不显示的人物（表） | 空 | 每行一个人物 ID（只能写数字）+ 备注 + 启用 |

- 卡上的整活儿内容：称号（最多 3 个，按战绩算。船型类如「泡泡大师」「隐轰投弹高手」；损失类如「诱导驾驶员」（常开诱导的船被击毁）、「众矢之的」（常被 10 人以上围攻）、「蛋舱常驻嘉宾」；击毁类如「旗舰猎手」「百亿猎手」「势力战老兵」「内鬼嫌疑人」「大战常客」「低安游侠」「零安居民」「单杀王」）、本报锐评（1 条，按战绩规则挑最贴切的）、读者来信、今日运势（宜 2 条、忌 2 条）、分类广告。全部只调侃游戏里的战绩，不写性别、地域、现实身份。想改说法：改插件源码 `src/core/pilot/copy/` 下的文案文件（只放句子，不放逻辑）。
- 游戏里设置的军团头衔（例如 `#Xxx-Yyy`）会原样显示在军团行上方，不用配置。
- 「不显示的人物」：写在表里的人，不管用名字、ID 还是链接查，机器人都只回「这个人物的战绩不在这里显示。」，不出图，也不出现在候选列表里。备注随便写（例如名字，只给你自己看）。ID 不是纯数字的行会被跳过，原因写在「市场状态」的配置问题里。
- 名字写得不完整时：做过「市场授权」（见 [EVE授权.md](EVE授权.md)）就用那个角色的授权做模糊搜索，列出最多 8 个候选（每个一个按钮，也可以回编号）；没做过就提示写完整名字。这个搜索只读，不需要额外设置。
- 每个群 / 私聊每分钟最多查 6 次，超过回「查得太快了，稍等一会」。同一个人 1 小时内再查直接用上次的图。
- 出图要 puppeteer，图里的中文要系统装有中文字体（见 README 的字体说明）。没有 puppeteer 或出图失败时，发文字版简报，内容一样但没有图。
- 回复里不写链接或域名；人物名、军团名里网址样子的片段会被换成「[链接]」。
- 命令入口：`KB`（不分大小写）、别名 `战绩`。`kb.auto` 在 @机器人 的消息里排在名单里网站的链接和击杀链接后面、物品名前面；这个人没有权限用 KB 时不自动识别。

## 工业

「制造」「制造比价」「反应」（包括「拆到原料」）用这一组。**什么都不填也能用**：这时只有「基础参考」（`制造 乌鸦级`：材料成本和时间，不算地点和税）。想按你们的地点、建筑、税来算，就把下面的「工业地点」「工业建筑」两个表格填上。公式见 [工业公式.md](工业公式.md)。

### 价格从哪里来

| 字段 | 默认 | 说明 |
|---|---|---|
| `industry.materialMarket` | `Jita 4-4` | 材料按哪个市场的价格算。填市场表格里的名称或别名。本群看不到这个市场时改用基准市场 |
| `industry.materialPriceType` | 出售价 | 材料按出售价 / 中间价 / 收购价算 |
| `industry.productMarket` | `Jita 4-4` | 成品值多少钱（算利润用）按哪个市场算 |
| `industry.productPriceType` | 出售价 | 成品按哪个价格算 |
| `industry.fallbackMarket` | 空 | 材料在材料市场没有价格时改用哪个市场，卡片上标 †。留空 = 列为「缺价格」，总成本标「不完整」 |
| `industry.sellFeesPct` | 0 | 算利润时从成品价值里扣掉的销售税和经纪费（%）。填 0 = 不扣，卡片上写「未计销售税和经纪费」 |

### 其他

| 字段 | 默认 | 说明 |
|---|---|---|
| `industry.meTeChoices` | `10/20, 5/10, 0/0` | 「高级」计算第 2 步列出来让人选的蓝图 ME/TE。每组写成 `ME/TE`，用逗号分开 |
| `industry.sccSurchargePct` | 4 | SCC 附加费（%）。游戏改了这个税率时才改 |
| `industry.npcFacilityTaxPct` | 0.25 | 在 NPC 空间站做（或者命令里写「建筑:无」）时的设施税（%）。游戏改了才改 |
| `industry.multibuyLanguage` | 英文名 | 「查看材料」另外发的那份清单（可以粘进游戏的「多重购买」窗口）用英文名还是中文名 |

ME 是蓝图的材料效率（0–10，越高越省材料），TE 是时间效率（0–20，越高越快）。

### 工业地点 `industry.locations`

一行一个地点。群友在命令里写的地点名就是这里的「名称」或「别名」，例如 `制造 乌鸦级 XX-1`。

| 列 | 填什么 | 默认 |
|---|---|---|
| 名称 | 地点的名字，例如 `XX-1`。不能重复 | 空 |
| 别名 | 别的叫法，用逗号分开。地点所在星系的中英文名自动算别名，不用填 | 空 |
| 星系 | 星系名或星系 ID。**必须填** | 空 |
| 谁能看到 | 所有群 / 只在授权群（其他群里看不到这个地点） | 只在授权群 |
| 默认地点 | 只能勾一个。卡片上的「快速计算」、按钮里换地点时先用它 | 关 |
| 默认 ME / 默认 TE | 在这个地点算、命令里又没写 ME/TE 时用 | 10 / 20 |
| 星系费用加成 % | 这个星系对安装费的额外加成，例如 `-50`。一般填 0 | 0 |
| 启用 | | 开 |
| 备注 | 写给自己看 | 空 |

- 高安的地点不能做反应，「反应」不会列出它。
- 地点的名称和别名不能用 `高级` `材料` `全部` `all` 这些词（它们是命令的参数）。

### 工业建筑 `industry.structures`

一行一座建筑，一个地点可以有好几座。

| 列 | 填什么 | 默认 |
|---|---|---|
| 地点 | 上面「工业地点」里的**名称** | 空 |
| 名称 | 建筑的简称，命令里用，例如 `大厂`（`制造 乌鸦级 XX-1 建筑:大厂`）。同一个地点里不能重复 | 空 |
| 建筑类型 | Raitaru（莱塔卢）、Azbel（阿兹贝尔）、Sotiyo（索迪约）、Athanor（阿塔诺）、Tatara（塔塔拉）等的名字或 typeID；NPC 空间站填 `NPC`；不要建筑加成填 `无` | 空 |
| 建筑 ID | 可以不填（只是记录） | 空 |
| 用途 | 制造 / 反应 / 制造和反应 / 提炼 / 反应和提炼 / 制造和提炼 / 全部。反应只能在精炼厂（阿塔诺、塔塔拉）做，高安不能做；「提炼」是给炼金术用的，建筑类型「无」不能提炼（NPC 空间站可以） | 制造 |
| 改装件 | 建筑上实际装的改装件，名字或 typeID，用逗号分开。插件按产品自动判断哪个生效 | 空 |
| 制造税 % | 游戏里建筑主人设的制造税率。就是 0.0.4 里的「设施税 %」，已经填的不用动 | 0 |
| 反应税 % | 反应的税率。**留空 = 和制造税一样**，所以已有的配置不用重填；填 0 就是 0 | 空 |
| 提炼税 % | 提炼（炼金）的税率。**留空 = 0**。用途含「提炼」却没填时，「市场状态」提醒「提炼税没填，按 0% 算」 | 空 |
| 有超旗舰船坞 | 这座建筑装了超级旗舰级船坞，能造超旗舰和泰坦。**只有索迪约装得上，而且只在 00 生效**；勾在别的建筑或别的安全等级上，「市场状态」里会报告，开关不生效。真实游戏里还要主权升级，插件不单独判断，这个开关就代表它 | 关 |
| 其他费用 % / 其他费用 ISK | 联盟另外收的钱：按预估物品价值收几 %，和/或每个工作固定收多少 ISK。没有就填 0 | 0 / 0 |
| 其他费用的名称 | 卡片上显示的名字，例如「联盟工业税」 | 其他费用 |
| 默认建筑 | 这个地点默认用哪座。没勾时用第一座 | 关 |
| 启用 | | 开 |
| 备注 | 写给自己看 | 空 |

- 建筑和改装件的加成数值来自物品数据，**不用填数字**。
- 哪种建筑能造什么，也来自物品数据里的建筑服务表，**不用填**：阿兹贝尔、索迪约、铁壁、星城按类型自动当作有旗舰级船坞；莱塔卢、NPC 空间站、建筑类型「无」只能造旗舰以下的东西，旗舰里只有货舰、跳货、逆戟鲸级。高安里的建筑不能造旗舰。
- 税是分开的：制造用「制造税」，反应用「反应税」，炼金的提炼用「提炼税」。NPC 空间站的制造税仍然是上面「NPC 空间站设施税」。
- 改装件尺寸和建筑不符、或者在这个星系的安全等级不生效时，「市场状态」的「配置问题」里会写出来。

### 拆到原料的设置

「制造 … 拆到原料」用的默认值。都有默认值，**不填也能用**；命令里写了就以命令为准（例如 `反应:买`）。

| 字段 | 默认 | 说明 |
|---|---|---|
| `industry.chainReaction1` 低级反应 | 造 | 月矿原料（低级反应）自己造还是直接买 |
| `industry.chainReaction2` 高级反应 | 造 | 高级反应自己造还是直接买 |
| `industry.chainComponents` 组件 | 造 | 组件自己造还是直接买 |
| `industry.chainOther` 其他 | 买 | T1 船体、R.A.M.、燃料块自己造还是直接买。卡片上的「继续拆」按钮就是把它改成造 |
| `industry.chainAlchemy` 炼金术 | 自动 | 自动 = 哪条路便宜用哪条；正常 = 只走反应；炼金 = 低级反应能炼金的都走炼金 |
| `industry.chainReactionLocation` 默认反应地点 | 空 | 命令里写的地点没有精炼厂时，反应放在这里。填工业地点表里的名称或别名。留空 = 自动用表里第一个能反应的地点 |
| `industry.reprocessLocation` 提炼地点 | 空 | 炼金的提炼放在哪个地点。留空 = 先找命令里写的地点，再找第一个有「提炼」建筑的地点；都没有时提炼税按 0 算，卡片上注明 |
| `industry.scrapmetalLevel` 废料处理技能等级 | 5 | 0–5 的整数。提炼率 = 50% ×（1 + 2% × 等级），5 级 = 55%。超出范围的数会改成最近的合法值，并在「市场状态」里提醒 |

- 两个地点填了不存在的名字、本群看不到的、或者那个地点没有合用的建筑，会当作没填，「市场状态」的「配置问题」里写明。
- 地点的名称和别名不能叫 `拆到原料` `明细` `反应` `组件` `其他` `低级反应` `高级反应`（它们是命令的参数）。

### 例子

一个地点、一座大型工厂：

- 工业地点：名称 `XX-1`，星系填你们的星系名，谁能看到「只在授权群」，勾「默认地点」。
- 工业建筑：地点 `XX-1`，名称 `大厂`，建筑类型 `Sotiyo`，用途「制造」，改装件填实际装的，设施税 `1`，勾「默认建筑」。

保存以后，在授权群里 @机器人 发 `制造 乌鸦级 XX-1`，结果卡片上应该写着「XX-1 · 大厂」和「设施税 1.00%」。

一个地点、三座建筑（名字都是编的），带反应和炼金：

| 名称 | 建筑类型 | 用途 | 制造税 | 反应税 | 提炼税 | 有超旗舰船坞 |
|---|---|---|---|---|---|---|
| 大厂 | Sotiyo | 制造 | 1 | 空 | 空 | 勾（XX-1 在 00 才生效） |
| 反应厂 | Tatara | 反应 | 0.2 | 0.5 | 空 | 关 |
| 炼金炉 | Athanor | 提炼 | 空 | 空 | 0.5 | 关 |

- 大厂：反应税留空，等于制造税；因为是纯「制造」用途，反应税用不上。
- 反应厂：制造税填了 0.2 但用途只有反应，反应时收 0.5%。
- 炼金炉：用途「提炼」，只在 `反应:炼金` 或自动挑到炼金时用，提炼税 0.5%。
- 不想让某个地点参与炼金，就不要给它的建筑勾「提炼」。

发 `制造 万古级 XX-1`：因为勾了「有超旗舰船坞」，能造；没勾时会回答「XX-1 造不了万古级（需要超级旗舰级船坞）」，并给能造的地点按钮。

### 常见的错

| 提示 | 原因 | 怎么改 |
|---|---|---|
| 工业地点第 N 行 X 没有填星系，已跳过 | 「星系」一栏空着 | 填星系名或星系 ID |
| 工业建筑第 N 行地点「X」不在工业地点表里，已跳过 | 「地点」写的不是地点表里的名称 | 照地点表里的「名称」抄 |
| 工业建筑第 N 行 X 已经有一座叫「Y」的建筑，已跳过 | 同一个地点里两座建筑同名 | 改掉一个 |
| 勾了多个默认地点，只有第一个（X）生效 | 「默认地点」勾了好几个 | 只留一个 |
| 「ME/TE 选项」里的 … 看不懂 | `meTeChoices` 写错了格式 | 写成 `10/20, 5/10` 这样 |
| 工业建筑第 N 行 … 装不上超级旗舰级船坞，「有超旗舰船坞」不生效 | 勾了「有超旗舰船坞」，但建筑类型不是索迪约 | 取消勾选，或者把建筑类型改对 |
| 工业建筑第 N 行 … 超级旗舰级船坞只能在 00 使用 | 勾了开关，但地点不在 00 | 取消勾选 |
| 工业建筑第 N 行 提炼税没填，按 0% 算 | 用途含「提炼」但「提炼税 %」空着 | 填提炼税；真的是 0 就填 0 |
| 「默认反应地点」「提炼地点」… 已当作没填 | 填的名字不在工业地点表里，或那个地点没有精炼厂 / 没有「提炼」建筑 | 照工业地点表里的名称抄，或给那个地点加建筑 |
| 群里写了地点却说找不到 | 这个群不是授权群，而地点是「只在授权群」；或者那一行没启用 | 检查「谁能看到」和「启用」 |

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 改了设置没生效 | 确认保存了（右上角的勾号「重载配置」，或 Ctrl+S）；保存后等几秒（插件在重载）；看日志里有没有这一项的「配置问题」 |
| 授权群里看不到联盟市场 | 在群里发 `本群ID`，看是不是「已授权」。不是：检查「授权群」里的 ID。是：管理员发 `市场状态` 看这个市场的状态 |
| 联盟市场出现在没授权的群里 | 那一行的「谁能看到」被改成了「所有群」，改回「自动」或「只在授权群」 |
| 「查价 物品」没列出某个市场 | 那一行「默认查价」是「不列」；或者是「自动」，但它既不是基准市场也不是玩家建筑；或者已经列满 8 个 |
| 价格后面没有 ▲▼ | 基准市场留空了；或者那一次基准市场的价格没有及时取到（再查一次就有）；或者差价不到 0.1% |
| 运费不显示 | 见「运费」一节的常见问题 |
| 管理员发「市场状态」没反应 | 见「权限 → 管理员」 |
| 日志里有一大串「配置问题」，不知道从哪里看起 | 从第一条开始，按提示里的分组名和行号找到那一行，对照本文对应的一节 |
