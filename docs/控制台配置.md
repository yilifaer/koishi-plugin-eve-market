# 控制台配置

本插件的所有设置都在 Koishi 控制台里改。这份文档按控制台里的分组，一项一项说明：填什么、默认是什么、有什么用、举例、常见的错。

> 下文的「联盟市场A」「XX-1」「1000000000001」都是编造的例子，换成你们自己的。Jita、Amarr、Perimeter 这些是游戏里公开的名字。
> 文中的「12345」端口只是举例，换成你自己浏览器地址栏里的端口。

## 打开配置页、保存

1. 在浏览器里打开 Koishi 控制台（你平时用的地址，例如经 SSH 隧道打开的 `http://127.0.0.1:12345`）。
2. 点左边的「插件配置」。
3. 在插件列表里点 **eve-market**。
4. 右边就是本插件的配置页：
   - 最上面是一段说明，第一行是「打开 EVE 授权页面」（联盟建筑市场用，见 [EVE授权.md](EVE授权.md)）。
   - 下面按分组排列：基本、显示、权限、市场、物品别名、查价、批量查价、运费、查价告示、EVE 授权、图片与截图、高级。「高级」默认是折叠的，点 `advanced` 那一行右边的「展开以编辑」按钮才能看到里面的设置。
5. 改完以后保存，见下一段。

### 怎么保存

配置页的右上角**没有写着「保存」两个字的按钮**，是一排小图标。鼠标移到图标上，会显示它的名字：

| 插件现在 | 右上角的图标 | 保存用哪一个 |
|---|---|---|
| 启用着（平时都是这样） | 方块「停用插件」、**勾号「重载配置」**，后面还有重命名、删除等 | 点勾号「**重载配置**」。它就是保存：把改动写进配置，再重载本插件一次 |
| 停用着 | 三角「启用插件」、**软盘「保存配置」** | 只保存不启用：点软盘「保存配置」。要启用：点三角「启用插件」 |

- 也可以直接按键盘上的 **Ctrl+S**（苹果电脑上是 Command+S），和点「重载配置」（或「保存配置」）一样。
- 「重载配置」不会丢掉你的改动，放心点。
- 下文和其他文档里说「保存」，都是指这一步。

保存以后：

- 本插件自己重载一次，几秒钟。这几秒里发的命令可能没有回应，过一会儿再发就好。
- **只重载本插件**，别的插件不受影响：LLBot、dcqq-bridge 的转发照常。（安装、升级、卸载插件才会让 Koishi 整体重载。）
- 已经下载的物品数据、ESI 的缓存、建筑市场的订单都还在，不用重新下载。

控制台上的样子：

- 每一项上面的英文是字段名，例如 `general.requireAt`（前面的 `general.` 是浅色的字），下面是中文说明。本文表格的第一列就是字段名，方便对照。
- 「市场」「授权群」这类是**表格**：一行一条，点这张表格标题右边的「**添加行**」加一行（新的一行加在最下面）；每一行最右边有上移、下移和删除（垃圾桶图标）三个小按钮。大多数表格每行有一个「启用」开关，关掉 = 这一行先不用，不会报错。
- 「管理员」这种一项一个值的**列表**，点它标题右边的「**添加项目**」加一项。
- 开关点一下切换；有固定选项的（例如「类型」）是下拉菜单。
- 每一项右边都有一个「…」按钮。改乱了想回到默认值：点「…」→「**恢复默认值**」，再保存。
- 建议一律在控制台里改，不要直接改 `koishi.yml` 文件。

## 写错了怎么办

写错的地方只影响它自己：写错的**那一行**被跳过，别的行、别的设置照常，插件照常加载。

去两个地方看哪里写错了：

1. **Koishi 日志**：控制台左边的「日志」。每次保存以后，每个问题写一行黄色的警告，例如：

   ```
   配置问题：市场第 6 行「位置」不是数字（NPC 空间站填空间站 ID），已跳过
   ```

2. **「市场状态」**：管理员私聊机器人（或者在授权群里 @机器人）发 `市场状态`，卡片下部有一行「配置问题」（在最后一行「命令冲突」的上面）。没有问题时写「配置问题：无」；有好几条时列出前 8 条，再多的写「另有 N 条，详见 Koishi 日志」。

看懂提示：

| 提示里的说法 | 意思 |
|---|---|
| 「市场第 6 行」 | 「市场」表格里从上往下数第 6 行。关掉「启用」的行也算在行数里 |
| 「已跳过」「这一行不生效」 | 这一行整行没有用上。改好再保存 |
| 「已忽略」「这一行的不生效」 | 这一行的某一部分（例如其中一个别名、一个网址）没有用上，其他照常 |
| 「已改用默认值」「已按 4 处理」 | 数字或选项写得不对，插件先用默认值或最接近的允许值。改好再保存 |
| 「有写错的字段（例如类型、启用写成了别的值），已跳过」 | 一般只在直接改 `koishi.yml` 时出现。在控制台里重新选一下这一行的下拉菜单和开关 |

- 有些问题要等物品数据加载好才查得出来，例如空间站 ID 不存在、星系名写错、别名指向的物品找不到。这些在保存后几秒内补写进日志；每周数据更新以后也会再查一遍。
- 「市场状态」只回应管理员，见下面「权限」一节。

## 基本

| 字段 | 默认 | 说明 |
|---|---|---|
| `general.requireAt` | 开 | 群里只处理 @机器人 的消息。私聊不受影响 |
| `general.allowSandbox` | 关 | 测试用：也在 Koishi 控制台的「沙盒」里回复（纯文字） |

- `requireAt`：保持打开。QQ 群主打开机器人的「接收群内全部消息」以后，机器人能看到群里所有消息；这个开关保证插件只回答 @ 它的消息，不会和群里别的机器人抢着回复。
- `allowSandbox`：QQ 机器人还没接好时，用控制台的「沙盒」试命令，做法见 [测试步骤.md](测试步骤.md) 的 A 部分。**测完关掉。**
- 不管这两个开关怎么设，插件都只在 QQ 官方机器人上回复（打开 `allowSandbox` 时再加上沙盒），不会在 LLBot 等 OneBot 机器人上回复。

## 显示

管价格怎么写、要不要按钮。默认值一般不用改；「样式自检」发现 QQ 上显示不对时再改。

| 字段 | 默认 | 可选 | 说明 |
|---|---|---|---|
| `display.output` | Markdown 卡片 | Markdown 卡片 / 纯文字 | QQ 上发 Markdown 卡片；QQ 拒收时自动改发纯文字。选「纯文字」就一律发纯文字 |
| `display.numberStyle` | 灰底等宽 | 灰底等宽 / 加粗 / 普通 | 卡片里完整价格的样式 |
| `display.priceDisplayMode` | `875,700,000 ISK（875.70M）` | 完整加简写 / 只要完整（`875,700,000 ISK`）/ 只要简写（`875.70M`） | 主要金额的写法：查价的单价和合计，批量查价的合计和运费（0.2.0 起还有工业的成本和利润） |
| `display.listPriceDisplayMode` | 只用简写 | 只用简写 / 和上一项相同 | 清单里每一行的价格：批量查价的明细、搜索结果、植入体套装。只用简写时消息不会太长 |
| `display.compactDecimals` | 2 | 0–4 | 简写保留几位小数：2 是 `875.70M`，0 是 `876M` |
| `display.thousandSeparator` | 开 | | 完整价格加千位分隔符：开是 `875,700,000`，关是 `875700000` |
| `display.showCurrency` | 开 | | 完整价格后面带「ISK」 |
| `display.clickable` | 带按钮 | 带按钮 / 不带 | 消息下面带可以点的按钮；选「不带」时只写编号和完整命令 |

常见情况：

- 卡片里价格两边多出反引号「`」，或者灰底显示得很怪：把 `numberStyle` 改成「加粗」或「普通」。
- 按钮点了没反应，或者带按钮的消息发不出去：先把 `clickable` 改成「不带」，再告诉开发者。
- `compactDecimals` 填了 0–4 以外的数，例如 6：日志写「显示：「简写的小数位数」应该在 0–4 之间，已按 4 处理」。

## 权限

决定谁是管理员、哪些群能看到联盟的价格。

### 先拿到 ID：「本群ID」

QQ 官方机器人看到的群和人，ID 都是一长串字母和数字，**不是群号，也不是 QQ 号**。用「本群ID」命令查看：

1. 在群里 @机器人 发 `本群ID`。
2. 机器人回 3 条消息：第 1 条是说明，第 2 条是**本群 ID**，第 3 条是**你的 ID**。长按就能复制。
3. 第 1 条里写着「本群现在：未授权」或「本群现在：已授权」。
4. 私聊机器人发 `本群ID`：回 2 条，第 2 条是你在私聊里的 ID。

第 1 条说明里有一句「管理员一栏填：qq: 加上你的 ID」（私聊里是「qq: 加上下一条的 ID」）。意思是：管理员一栏里可以在 ID 前面加上 `qq:`，也可以不加，两种写法一样。**不要把「qq: 加上」这几个字抄进去**，只抄 ID 本身。

- 同一个人在不同群里、在私聊里的 ID **可能不一样**（待实测）。所以管理员一栏：**群里拿到的 ID 和私聊里拿到的 ID 都加进去**，各占一项。还不能私聊机器人时，先只加群里的。
- 如果第 1 条里还有一行「你的跨群 ID」，这个 ID 在所有群和私聊里都一样，也加进去。
- **重新创建 QQ 机器人以后，所有 ID 都会变**，要重新查、重新填。
- 在控制台沙盒里查到的 ID 前面带着 `sandbox:`，原样照抄。

### 管理员 `access.admins`

默认是空的。一项填一个用户 ID，前面写不写 `qq:` 都行。

管理员能用这几个命令（别人发了没有任何反应，帮助里也看不到）：

| 命令 | 在哪里回应 |
|---|---|
| 市场状态、市场授权 | 只在**私聊**或**授权群**里。在没授权的群里发也没有反应，这是正常的 |
| 样式自检 | 哪个群都行 |

另外：管理员私聊机器人时，按授权群对待（能看到联盟市场）。Koishi 里权限等级 4 以上的账号也算管理员，一般用不到。

怎么加：

1. 在群里 @机器人 发 `本群ID`，长按第 3 条（你的 ID）复制。
2. 控制台 → eve-market →「权限」→ 点 `access.admins` 右边的「添加项目」，在新出现的框里粘贴。
3. 能私聊机器人的话，私聊发 `本群ID`，长按第 2 条复制，再「添加项目」粘贴一次。
4. 保存。
5. 检查：在群里 @机器人 发 `帮助 样式自检`（私聊里直接发）。回复的标题是「**样式自检（管理员）**」就对了；回的是帮助总表（标题「EVE 市场助手」），说明你在这里还不算管理员。

没算上管理员时：多半是填的 ID 和你发命令的地方对不上（例如只填了私聊里拿到的 ID，却在群里发）。在你发命令的地方再发一次 `本群ID`，把那里显示的「你的 ID」也加进去。

注意：在**没授权的群**里，管理员发 `帮助` 也看不到「管理」那一行，发 `市场状态` 也没有反应，这是正常的（见上表）。所以上面用 `帮助 样式自检` 检查，它在哪里都能用。

### 授权群 `access.allowedGroups`

表格，每行：群 ID、备注、启用。默认是空的。

授权群能看到：

- 「谁能看到」是「只在授权群」的市场。联盟建筑市场默认就是这样；
- 「只在授权群」的运费路线和查价告示；
- 管理员可以在这个群里用「市场状态」「市场授权」。

没授权的群照样能查 Jita 等公开市场，只是看不到上面这些，就像它们不存在一样。

怎么加：

1. 在要授权的群里 @机器人 发 `本群ID`，长按第 2 条（本群 ID）复制。
2. 控制台「权限」→ 点 `access.allowedGroups` 右边的「添加行」，在新的一行里填：
   - 群 ID：粘贴；
   - 备注：写个好认的名字，例如「联盟主群」；
   - 启用：打开。
3. 保存。
4. 回到群里再发一次 `本群ID`，第 1 条应该写「本群现在：已授权」。

常见的错：

| 现象或提示 | 原因 | 怎么改 |
|---|---|---|
| 填了以后「本群ID」还是「未授权」 | 填成了第 3 条（你的 ID） | 换成第 2 条 |
| 授权群第 2 行「群 ID」里有空格，已跳过 | 复制时带进了空格或换行 | 重新复制粘贴 |
| 授权群第 2 行「群 ID」为空，已跳过 | 这一行没填 ID | 填上，或者删掉这一行 |
| 以前好好的，忽然所有群都变成「未授权」 | 重新创建过 QQ 机器人，ID 全变了 | 每个群重新发 `本群ID`，重新填 |

### 授权私聊用户 `access.allowedUsers`

表格，每行：用户 ID、备注、启用。默认是空的。日志里这张表叫「授权私聊用户」。

- 这里的人私聊机器人时，按授权群对待：能看到联盟市场、「只在授权群」的运费和告示。
- 管理员自动算在内，不用重复填。
- 填**私聊里**拿到的 ID（让对方私聊机器人发 `本群ID`，把第 2 条发给你）。

查价、批量查价、走势、搜索用到的市场都在这张表里，一行一个市场。

|---|---|---|---|---|---|
| Jita 4-4 | 4-4 | NPC 空间站 | 60003760 | 自动（它是基准市场，所以列出） | 0 |
| Amarr | | NPC 空间站 | 60008494 | 不列 | 10 |
| Dodixie | | NPC 空间站 | 60011866 | 不列 | 11 |

### 每一列

| 列 | 填什么 | 新加一行时的默认 |
|---|---|---|
| 名称 | 群友查价时打的名字，卡片上的小标题也是它。不能重复 | 空 |
| 别名 | 其他叫法，多个用逗号分隔（中英文逗号、顿号、分号都行），不区分大小写 | 空 |
| 类型 | NPC 空间站 / 整个星系 / 整个星域 / 玩家建筑 | NPC 空间站 |
| 位置 | 按类型填，见下一节 | 空 |
| 建筑所在星系 | 只用于玩家建筑，见后面 | 空 |
| 启用 | 关掉 = 先不用这一行 | 开 |
| 默认查价 | 自动 / 列出 / 不列：「查价 物品」不写市场时列不列这个市场 | 自动 |
| 排序 | 数字，小的排在前面 | 0 |
| 谁能看到 | 自动 / 所有群 / 只在授权群 | 自动 |
| 授权档案 | 只用于玩家建筑：用哪个 EVE 授权档案。别的类型这一格写什么都不用 | `default` |
| 备注 | 写给自己看，插件不用 | 空 |

### 类型和位置

| 类型 | 位置填什么 | 例子 | 自动加上的别名 |
|---|---|---|---|
| NPC 空间站 | 空间站 ID（纯数字） | `60003760`（Jita 4-4） | 空间站所在星系的中英文名，例如 `Jita`、`吉他` |
| 整个星系 | 星系名（中文或英文）或星系 ID | `Perimeter`、`皮尔米特` 或 `30000144` | 星系的中英文名 |
| 整个星域 | 星域名（中文或英文）或星域 ID | `The Forge`、`伏尔戈` 或 `10000002` | 没有 |
| 玩家建筑 | 建筑 ID（纯数字） | `1000000000001` | 没有 |

- NPC 空间站只算挂在这个空间站里的订单；「整个星系」「整个星域」算整个星系、星域里的订单。
- 有了自动别名，`查价 吉他 乌鸦级` 和 `查价 Jita 4-4 乌鸦级` 是一样的。自动别名和别的市场的名称、手写别名撞了时，自动的那个不用，也不报告。
- 想加别的 NPC 交易中心，最简单的是用「整个星系」，位置填星系名，不用去找空间站 ID。
- 不知道星系的正确写法：发 `翻译 星系名` 看看中英文名。
- 玩家建筑的 ID 在 EVE 授权页面里按名字搜，搜索结果下面直接写着这一行怎么填，见 [EVE授权.md](EVE授权.md) 第 4 步。

### 默认查价

群友发「查价 物品」、不写市场时，列出哪些市场：

- **自动**：玩家建筑列出；基准市场（「查价」分组的 `price.baseMarket`，默认 Jita 4-4）列出；其他不列。基准市场留空时，改成列出第一个公开市场。
- **列出 / 不列**：照你选的。
- 列出的市场按「排序」从小到大排，排序一样时按表格里的先后；最多列 8 个。
- 只列这个群看得到的：没授权的群只会看到公开的那几个。

例：想让 Amarr 也出现在「查价 乌鸦级」的结果里，把 Amarr 那一行的「默认查价」改成「列出」。

### 谁能看到

| 选项 | 意思 |
|---|---|
| 自动 | 玩家建筑 = 只在授权群；其他类型 = 所有群 |
| 所有群 | 任何群都能看到 |
| 只在授权群 | 只有授权群、授权私聊用户和管理员的私聊能看到 |

- 看不到的群里，这个市场就像不存在一样，写它的名字也查不到。
- **把联盟建筑改成「所有群」，联盟的价格就会出现在所有群里**，一般不要这样做。

### 授权档案和建筑所在星系（只用于玩家建筑）

- **授权档案**：写 EVE 授权页面里的档案名，一般就是 `default`。只能用文字、数字、`-` 和 `_`，最多 32 个字。
- **填了授权档案**：「建筑所在星系」可以空着，授权以后插件自己查。填上也行；填错了日志里会提醒，但这一行照常用。
- **授权档案留空** = 不用授权，只读这个建筑公开的订单（从星域订单里找，这个用法还没有实测）。这时**必须**填「建筑所在星系」，否则这一行跳过。
- 「EVE 授权」分组里还没填 Client ID 时，用了授权档案的每一行都会提示「…使用的授权档案 default 还没有授权」。按 [EVE授权.md](EVE授权.md) 做完就好。

### 名称和别名的规则

- 名称不能重复。不区分大小写，`Jita 4-4` 和 `jita 4-4` 算重复。重复的后一行跳过。
- 名称和别名**不能**用下面这些写法，因为它们会和命令的参数混在一起：
  - 价格类型的词：`sell` `出售` `出售价` `卖` `卖价` `卖单` `buy` `收购` `收购价` `买` `买价` `买单` `mid` `中间` `中间价` `中` `split`；
  - `全部` `all` `高级` `材料` `刷新`；
  - 纯数字（会被当成数量）；
  - `95%`、`-5%`、`95折` 这种（会被当成价格调整）；
  - `从81` 这种「从」加数字（会被当成完整清单的页码）；
  - 以 `#` 开头的。
- 一个别名已经是别的市场的名称或别名时，后面那一行的这个别名不生效，日志里会写。

### 例子

**加一个联盟建筑市场**（先按 [EVE授权.md](EVE授权.md) 做好授权）：

| 名称 | 别名 | 类型 | 位置 | 建筑所在星系 | 默认查价 | 谁能看到 | 授权档案 |
|---|---|---|---|---|---|---|---|
| 联盟市场A | 市场A, A市 | 玩家建筑 | 1000000000001 | XX-1 | 自动 | 自动 | default |

保存以后，在授权群里发 `查价 乌鸦级`，会多出「联盟市场A」一节；没授权的群看不到。

**加一个整个星系的市场**：名称 `Perimeter`，类型「整个星系」，位置 `Perimeter`，默认查价「不列」。之后可以发 `查价 Perimeter 乌鸦级`，也可以写 `查价 皮尔米特 乌鸦级`。

**临时不用 Hek**：把 Hek 那一行的「启用」关掉，保存。

## 物品别名

表格，每行：别名、目标物品、启用、备注。默认是空的。

- 给物品加一个叫法。群友写别名，就等于写目标物品。
- 目标物品可以写英文名、中文名，或者 typeID（物品编号，例如 `638` 或 `#638`）。
- 别名不区分大小写，空格也不算：`大 鸟` 和 `大鸟` 算同一个。
- 黑话表（eve-cn-slang 的 `glossary.yaml`）里的叫法会自动接入，不用在这里重复填。这里写的和黑话表冲突时，**以这里为准**。
- 别名不能和另一个物品的正式名称一样（按正式名称查询永远优先）。

例子：

| 别名 | 目标物品 | 备注 |
|---|---|---|
| 大鸟 | Raven | |
| 海军乌鸦 | 乌鸦级海军型 | |

保存以后，`查价 大鸟` 和 `查价 乌鸦级` 一样。

常见的错（提示前面都带着「物品别名第 N 行」）：

| 提示 | 原因 | 怎么改 |
|---|---|---|
| 「别名」为空，已跳过 | 别名没填 | 填上，或删掉这一行 |
| 别名「X」没有写目标物品，已跳过 | 目标没填 | 填上 |
| 别名「X」和第 M 行重复，已跳过 / 和第 M 行的写法相同，已跳过 | 两行的别名一样 | 删掉一行 |
| 别名「X」的目标「Y」找不到对应的物品，这一行不生效 | 目标写错 | 写游戏里的完整名字。可以先发 `查价 Y` 试试能不能查到 |
| 别名「X」的目标「Y」对应多个物品，请改写成 #typeID，这一行不生效 | 这个名字对应好几个物品。例如中文「救赎级」有两个物品（Absolution 和 Salvation） | 改写英文名，例如 `Absolution` |
| 别名「X」和物品「Z」的名字相同，按名字查询优先，这一行不生效 | 别名就是另一个物品的正式名称 | 换个别名 |
| 别名「X」里没有可用的字，已跳过 | 只写了符号 | 换个别名 |

## 查价

| 字段 | 默认 | 说明 |
|---|---|---|
| `price.baseMarket` | `Jita 4-4` | 基准市场 |
| `price.defaultQuantities` | 一行：PLEX，500 | 不写数量时另外给出的合计 |

### 基准市场 `price.baseMarket`

填「市场」表格里的名称或别名。它有这几个用处：

1. 查价卡片上，其他市场的价格后面显示和它比的涨跌。例如 Amarr 出售价后面的「▲4.5%」，表示比 Jita 贵 4.5%；卡片最下面写「▲▼ 与 Jita 4-4 比较」。相差不到 0.1% 时不画。
2. 「走势」「搜索」不写市场时用它。
3. 批量查价的运费只在用它估价时显示（见「运费」一节）。
4. 「默认查价」选「自动」时，它会被列出。
5. 别的设置引用的市场（例如批量查价的默认市场）写错了、或者本群看不到时，改用它。

- 留空：不显示涨跌，也不显示运费；走势、搜索改用第一个能用的公开市场。
- 写了表格里没有的名字：日志写「查价：「基准市场」写的「X」找不到这个市场，改用 Jita 4-4」（改用的是第一个公开市场）。

### 默认数量 `price.defaultQuantities`

表格，每行：物品、数量。默认一行：PLEX，500。

- 查价时没写数量，就按这里的数量另外算一个合计。默认设置下发 `查价 PLEX`，标题里写「×500」，每个价格后面多一个「合计」。
- 自己写了数量（`查价 PLEX*100`）时按写的算。
- 物品的写法和查价一样：英文名、中文名或 typeID，必须只对应一个物品。
- 数量是 1 到 10¹²（一万亿）之间的整数。

常见的错（提示前面都带着「默认数量第 N 行」）：

| 提示 | 怎么改 |
|---|---|
| 「物品」为空，已跳过 | 填上物品，或删掉这一行 |
| X 的数量要是 1 到 10¹² 之间的整数，已跳过 | 改成整数 |
| X 和第 M 行重复，已跳过 | 删掉一行 |
| 「物品」X 找不到对应的物品，这一行不生效 | 写游戏里的完整名字（英文或中文）。可以先发 `查价 X` 试试 |
| 「物品」X 不能在市场上交易，这一行不生效 | 这个东西不能在市场上买卖，删掉这一行 |
| 「物品」X 对应多个物品，请改写成 #typeID，这一行不生效 | 写完整的英文名；中文名对应好几个物品时改写成 `#typeID`。例如中文「救赎级」有两个物品，写 `Absolution` 或 `#22448` |
| 「物品」X 不是一个确定的物品，请写完整的名字或 #typeID，这一行不生效 | 只写了名字的一部分。写完整的名字，或者 `#typeID` |

## 批量查价

| 字段 | 默认 | 说明 |
|---|---|---|
| `appraisal.defaultMarket` | `Jita 4-4` | 「批量查价」不写市场时在哪个市场估价。填市场的名称或别名。本群看不到这个市场时改用基准市场 |
| `appraisal.defaultPriceType` | 出售价 | 出售价 / 中间价 / 收购价 |
| `appraisal.fallbackMarket` | 空 | 回退市场 |

- 这里只是不写时的默认。群友每次都可以在命令里改，例如 `批量查价 Amarr buy -5%`：在 Amarr 按收购价估、再减 5%。
- 例：联盟群里大家主要在联盟市场A 买卖，可以把默认市场改成 `联盟市场A`。没授权的群看不到它，会自动改用 Jita 4-4。注意运费只在用基准市场估价时显示。

**回退市场**：

- 某个物品在选的市场**没有挂单**时，改用回退市场的价格。卡片上这个物品标 †，下面写「† 标记的物品 … 没有价格，已改用 … 出售价」。
- 留空 = 不回退：这些物品写在「没有计入合计」里。
- 整个市场暂时用不了（例如联盟建筑授权异常）时**不会**回退。卡片上直接说明这个市场不可用，清单已经保存，可以点按钮改用别的市场。

常见的错：「默认市场」「回退市场」写了表格里没有的名字，日志写「批量查价：「默认市场」写的「X」找不到这个市场，改用 Jita 4-4」。改成市场表格里的名称或别名。

## 运费

表格 `freight.routes`。默认是空的，空 = 卡片上不显示运费。

| 列 | 填什么 | 默认 |
|---|---|---|
| 名称 | 运到哪里。卡片上显示「运到 名称」 | 空 |
| ISK/m³ | 每立方米多少 ISK | 0 |
| 押金费率 % | 押金的百分之几。填 `1` 就是 1% | 0 |
| 单单最大体积 m³ | 一个合同最多装多少立方米；`0` = 不限 | 0 |
| 谁能看到 | 所有群 / 只在授权群 | 只在授权群 |
| 启用 | | 开 |
| 备注 | 写给自己看 | 空 |

### 什么时候显示

- 只在**用基准市场估价**时显示。默认就是 `批量查价` 不写市场、在 Jita 估价的时候。在 Amarr、联盟市场估价时不显示，因为运费算的是「从 Jita 运过去」。
- 最多显示 2 条：表格里从上往下，本群能看到的前 2 条。
- 「查价」分组的基准市场留空时，运费一律不显示。

### 怎么算

```
运费     = 打包体积 × ISK/m³ + 押金 × 押金费率
押金     = 清单里每样东西的 Jita 出售价 × 数量，全部加起来
到货成本 = 批量查价的合计（加减百分比以后的）+ 运费
```

- 体积按**打包后**的体积算（船按打包体积）。
- 押金一律按基准市场（Jita）的**出售价**算，不管这次估价用的是收购价，还是写了 `-5%`。
- Jita 没有出售价的物品不算进押金，卡片上会写「（N 种物品没有 Jita 4-4 出售价，押金没有算进去）」。
- 总体积超过「单单最大体积」时，卡片上提醒要拆成几单（总体积 ÷ 单单最大体积，有小数就进一）。**运费本身不变**，还是按总体积算。

### 例子

运费表格里一行：名称 `XX-1`，ISK/m³ `800`，押金费率 `1`，单单最大体积 `30000`。

群友粘贴一份清单（不写市场，默认按 Jita 出售价），打包体积 50,328 m³，Jita 出售价合计 379,312,120 ISK：

```
运费     = 50,328 × 800 + 379,312,120 × 1%
         = 40,262,400 + 3,793,121
         = 44,055,521 ISK（约 44.06M）

到货成本 = 379,312,120 + 44,055,521
         = 423,367,641 ISK

拆单     = 50,328 ÷ 30,000 = 1.68 → 2 单
```

卡片上大致是这样一行：

```
🚚 运到 XX-1 约 44,055,521 ISK（44.06M）· 800 ISK/m³ + 押金 1% · 到货成本 423.37M · 超过 30,000 m³，需要拆成 2 单
```

如果群友写的是 `批量查价 -5%`：合计变成 360,346,514 ISK；押金还是按 379,312,120 算，所以运费还是 44,055,521；到货成本 = 360,346,514 + 44,055,521 = 404,402,035 ISK。

| 卡片上没有运费 | 估价市场不是基准市场；或者这个群没授权、路线是「只在授权群」；或者路线的「启用」关了；或者清单里一个价格都没有 | 逐条检查 |

## 查价告示

表格 `notices.list`。默认是空的。

| 列 | 填什么 | 默认 |

| 内容 | 一行字，不超过 80 个字，不能带网址 | 空 |

| `render.influenceMapUrl` | `https://www.verite.space/maps/influence/influence.png` | 「势力图」发的图片 |
| `render.coalitionMapUrl` | `https://www.verite.space/maps/coalition/coalitioninfluence.png` | 「联盟势力图」发的图片 |
| `render.brAuto` | 开 | @机器人 的消息里带战报链接时自动截图 |

- 图片地址一般不用改。要恢复默认：点这一项右边的「…」→「恢复默认值」，再保存；也可以把上表里的地址抄回去。
- 地址留空 = 关掉这个命令。群友发「势力图」时回复「势力图没有开启（控制台里没有填图片地址）。」
- 地址必须 `http://` 或 `https://` 开头。写错时日志写「图片与截图：「势力图地址」不是 http:// 或 https:// 开头的网址，已改用默认地址」。
- `brAuto` 打开时：群里 @机器人 的消息、或者私聊消息里带 BR 工具的战报链接，就自动截图。关掉以后，只有写明「战报 链接」才截图。
- 走势图和战报截图要用 puppeteer 插件，没有它时的情况见 [README](../README.md) 的「走势图和战报截图（puppeteer）」一节。

## 高级

默认折叠：点 `advanced` 那一行右边的「展开以编辑」。**一般不用改。**

| 字段 | 默认 | 说明 |
|---|---|---|
| `advanced.manifestUrl` | eve-cn-slang 的物品数据地址（两个，见下面） | 物品数据清单的网址 |
| `advanced.glossaryUrl` | eve-cn-slang 的黑话表地址（两个，见下面） | 黑话表的网址 |
| `advanced.esiContact` | 空 | 可选：写进 ESI 请求头的联系方式 |

- 网址可以写好几个，用 `||` 隔开。按顺序试，第一个不行再试下一个。
- 默认值是 GitHub 的地址加上 jsDelivr 的备用地址。要恢复默认：点这一项右边的「…」→「恢复默认值」，再保存。这样不行时，把下面两行原样抄回去：

  `advanced.manifestUrl`：

  ```
  https://raw.githubusercontent.com/yilifaer/eve-cn-slang/main/official/data/manifest.json || https://cdn.jsdelivr.net/gh/yilifaer/eve-cn-slang@main/official/data/manifest.json
  ```

  `advanced.glossaryUrl`：

  ```
  https://raw.githubusercontent.com/yilifaer/eve-cn-slang/main/glossary.yaml || https://cdn.jsdelivr.net/gh/yilifaer/eve-cn-slang@main/glossary.yaml
  ```

- 网址留空 = 不联网，只用插件自带的数据（升级插件时才会变新）。数据怎么更新见 [数据说明.md](数据说明.md)。
- `esiContact`：出问题时 CCP 能联系到你，例如你的游戏角色名（英文）。只能用英文字母、数字和常见符号，中文会被去掉；最多 100 个字符。不填也没关系。

常见的错：

| 提示 | 怎么改 |
|---|---|
| 高级：「物品数据网址」里的「X」不是 http:// 或 https:// 开头的网址，已忽略 | 检查有没有漏掉 `https://`，或者两个网址之间少了 `\|\|` |
| 高级：「ESI 联系方式」只能用英文字母、数字和常见符号，其他字符已去掉 | 改成只有英文和数字 |

## 工业（0.2.0）

「制造」「制造比价」「反应」用的「工业」分组（材料和成品的市场、价格类型、工业地点、工业建筑、改装件、税和其他费用）在 **0.2.0** 加入控制台。现在的版本里还没有这一组。升级到 0.2.0 以后，没填之前按默认值工作，不会报错。到时这份文档会补上这一节。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 改了设置没生效 | 确认保存了（右上角的勾号「重载配置」，或 Ctrl+S）；保存后等几秒（插件在重载）；看日志里有没有这一项的「配置问题」 |
| 授权群里看不到联盟市场 | 在群里发 `本群ID`，看是不是「已授权」。不是：检查「授权群」里的 ID。是：管理员发 `市场状态` 看这个市场的状态 |
| 联盟市场出现在没授权的群里 | 那一行的「谁能看到」被改成了「所有群」，改回「自动」或「只在授权群」 |
| 「查价 物品」没列出某个市场 | 那一行「默认查价」是「不列」；或者是「自动」，但它既不是基准市场也不是玩家建筑；或者已经列满 8 个 |
| 价格后面没有 ▲▼ | 基准市场留空了；或者那一次基准市场的价格没有及时取到（再查一次就有）；或者差价不到 0.1% |
| 运费不显示 | 见「运费」一节的常见问题 |
| 管理员发「市场状态」没反应 | 见「权限 → 管理员」 |
| 日志里有一大串「配置问题」，不知道从哪里看起 | 从第一条开始，按提示里的分组名和行号找到那一行，对照本文对应的一节 |
