# QQ 机器人注册（QQ 开放平台）

本插件只在 **QQ 官方机器人** 上回复。官方机器人要在 QQ 开放平台（q.qq.com）上创建，再把它的 AppID 和 AppSecret 填进 Koishi 的 adapter-qq 插件。

整个过程分两段：

- **现在就能做**（大约 30 分钟）：创建机器人 → 复制 AppID 和 AppSecret → 建测试群、把机器人拉进去 → 在 Koishi 里填 adapter-qq → 确认上线 → 在测试群里发「本群ID」「样式自检」。
- **测试通过以后**：提审、上线，把机器人拉进联盟的群；可选：配置「/」指令面板。

第 1–5 步只在 QQ 开放平台和 QQ 上操作，不碰 Koishi，随时可以做。**第 6 步之前**，要先在 Koishi 里做好几件事（备份、给旧插件设过滤器、挑没人说话的时候装好本插件），见第 6 步开头。整体的先后顺序见 [README 的「文档」一节](../README.md#文档)。

> 下文的「测试群」「联盟市场A」都是举例，换成你自己的。
> 标着「待实测」的地方是开放平台的界面或规则还没在真机上逐一确认，以你看到的为准；有出入请告诉开发者。
> 开放平台的界面经常改版，按钮的名字可能和这里写的不完全一样，找意思相近的那一个。

## 开始之前

要准备的东西：

| 东西 | 用途 |
|---|---|
| 手机 QQ | 扫码登录开放平台、把机器人拉进群 |
| 一个你自己是**群主**的 QQ 群，人数不超过 20（待实测） | 测试群。可以新建一个，只拉一两个小号进去 |
| 密码管理器，或者本机一个**不同步到网盘**的文本文件 | 存 AppSecret |
| 能打开 Koishi 控制台的浏览器 | 填 adapter-qq、填本插件的配置 |

账号的情况分两种：

- **已经认证的账号**（企业认证，或者已经做过个人认证）：不用再做认证，直接创建机器人。发布以后可以给别人的群用。
- **没有认证的个人账号**：也能创建机器人，但发布之前**只有你自己能用**，而且只能在你当群主的群里用。要让别人用、要提审上线，先按页面提示做「个人认证」（身份证和刷脸）。

## 先分清三个「沙箱 / 沙盒」

这三个名字很像，但完全是三样东西，别搞混：

| 名字 | 在哪里 | 干什么 | 平时 |
|---|---|---|---|
| 开放平台的「沙箱配置」 | q.qq.com 机器人的管理页 | 让还没上线的机器人进你的测试群 | 测试时用 |
| adapter-qq 配置里的 `sandbox`（是否开启沙箱模式） | Koishi 控制台 → adapter-qq | 让机器人改连 QQ 的测试环境 | **关** |
| Koishi 的「沙盒」插件 | Koishi 控制台左边的「沙盒」 | 不用 QQ 也能试命令 | 测试步骤 A 用 |

## 第 1 步：创建机器人

1. 用电脑浏览器打开 `https://q.qq.com`，用手机 QQ 扫码登录。
2. 进入「机器人」，点「创建机器人」。
3. 名称、头像、简介可以先随便填，**提审时会一起审核**，上线以后每月只能改 5 次。正式的名字等提审前再想好（见第 10 步）。
4. 创建完成后，进入这个机器人的管理页。

## 第 2 步：复制 AppID 和 AppSecret

1. 在机器人的管理页找到「开发设置」（一般在「开发」下面）。
2. 复制 **AppID**。注意：AppID **不是**机器人的 QQ 号。AppID 不用保密。
3. 生成并复制 **AppSecret**。注意：
   - 页面上如果还有一个旧的「Token」字段，不用管它，Koishi 用的是 AppSecret。
   - **AppSecret 只能复制一次**，以后再想看只能重置。马上存进密码管理器，或者本机一个不同步到网盘的文本文件。
   - **不要截图，不要发到任何聊天里**（包括发给开发者）。它只填在 Koishi 控制台里。
   - 丢了、或者怀疑泄露了：在开发设置里重置。旧的立即失效，把新的填回 Koishi（第 6 步）就行。
4. npm 令牌、EVE 开发者网站的 Secret Key 也照这个办法保管。

## 第 3 步：确认接入方式是 WebSocket

1. 在开发设置里找「事件订阅与回调地址」之类的地方（位置待实测）。
2. 接入方式保持 **WebSocket**（新机器人一般默认就是）。**回调地址不用填**：那是 webhook 方式用的，要求公网 HTTPS，我们用不到。
3. 同一页如果有「IP 白名单」：**现在先空着**（空着一般表示不限制，待实测）。提审时如果要求填，见第 10 步。

## 第 4 步：建测试群，把机器人拉进去

机器人上线之前，只能在测试群里用。

1. 在 QQ 里建一个群（或者用一个现成的），**你自己是群主**，人数不超过 20（待实测）。
2. 回到开放平台，找「沙箱配置」→「在QQ群配置」，把这个群加进去。页面上没有这一项就跳过。
3. 找「使用范围与人员」，页面上有一个二维码。用手机 QQ 扫码，打开机器人的资料卡，点「添加到群聊」（或者意思相近的按钮），选测试群。
4. 回到测试群，群成员列表里应该能看到机器人（名字旁边有「机器人」字样）。
5. 「使用范围与人员」里还可以加最多 20 个「内部体验」成员（待实测）。想让朋友帮忙测，就把他们加进去。

只有群主或管理员能把机器人拉进群。

## 第 5 步（可选）：单聊（也就是私聊机器人）

开放平台把「私聊机器人」叫做**单聊**。下文和其他文档里一律叫「私聊」，是同一件事。

在「沙箱配置」或「使用范围」里找「消息列表单聊」之类的选项，需要申请就申请（待实测）。

开不了也不要紧：所有管理操作在授权群里也都能做。能私聊的话，私聊里拿到的 ID 也加进管理员（见第 8 步）。

## 第 6 步：在 Koishi 里填 adapter-qq

**做这一步之前**，先按 [从旧插件迁移.md](从旧插件迁移.md) 做完第 1 步（备份）、第 2 步（给留在 LLBot 上的插件设过滤器），和第 3 步的第 1–3 点（挑群里没人说话的时候装好本插件、启用）。否则 adapter-qq 一启用，别的插件也会经官方机器人回答。想先在控制台的沙盒里试一遍的，也在这之前做 [测试步骤.md](测试步骤.md) 的 A 部分。

1. 打开 Koishi 控制台 → 「插件配置」。
2. 在左边的插件列表里找到 **adapter-qq**。它已经装好了，只是停用着（名字是灰色的）。**用这个已有的条目，不要再添加一个新的。**
   - 适配器可能放在一个叫「adapter」之类的分组里（分组名前面有一个小三角）。看不到时，点分组名展开再找。
   - 整个列表里都真的没有 adapter-qq 时，才到插件市场搜索 `adapter-qq` 安装。注意：安装会让整个 Koishi 重启一次（转发断大约 20 秒），挑群里没人说话的时候做。
3. 点开 adapter-qq，按下表填写（括号里是控制台上显示的说明）：

   | 配置项 | 填什么 |
   |---|---|
   | `id`（机器人 id） | 第 2 步复制的 **AppID** |
   | `secret`（机器人密钥） | 第 2 步复制的 **AppSecret** |
   | `type`（机器人类型） | `public`（填 `private` 也行） |
   | `sandbox`（是否开启沙箱模式） | **关** |
   | `endpoint`（要连接的服务器地址） | 不改，保持默认的 `https://api.bot.qq.com/` |
   | `intents`（需要订阅的机器人事件） | **只勾 `USER_MESSAGE`**，别的都不勾 |
   | `retryWhen`（发送消息遇到平台错误码时重试） | 留空 |
   | `protocol`（选择要使用的协议） | `websocket` |
   | `gatewayUrl`（覆写 WebSocket 地址） | 留空 |
   | 高级设置：`manualAcknowledge`（手动响应回调消息） | 关 |
   | 高级设置里的其他项 | 不动 |

   几点说明：

   - `type` 的 `public` / `private` 是 QQ 频道「公域 / 私域」的旧概念，和「是否公开发布」无关，只影响频道消息，对 QQ 群没有影响。实测填 `private` 也能正常用。
   - `USER_MESSAGE` 包含群里 @机器人 的消息和私聊消息，本插件只需要这些（实测只勾这一项就够）。本插件的按钮是「点一下填进输入框」的指令按钮，不用回调，所以不勾 `INTERACTIONS`。
   - **一项都不勾也能保存、能启用**，但机器人收不到消息，日志每隔几秒报一次 `invalid intents`。看到它就回来勾上 `USER_MESSAGE`。
4. 填完以后看右上角的一排小图标（鼠标移上去会显示名字）：先点**软盘图标「保存配置」**，再点**三角图标「启用插件」**。也可以按 Ctrl+S 保存。
5. 启用、停用、改配置都只会重载 adapter-qq 这一个插件，不影响 LLBot 和 Discord 转发。

AppSecret 只填在这里。不要写进任何文件、聊天或截图。

## 第 7 步：确认机器人上线

1. 启用后等十几秒。
2. 看控制台最下面的状态栏：应该出现这个机器人（头像和名字），状态是在线。
3. 打开控制台左边的「日志」，看 adapter-qq 相关的几行：
   - 正常：有一行连接服务器的信息（大致是 `connect to server: wss://...`），后面**没有**黄色或红色的警告。
   - 不正常：出现黄色或红色的警告，或者状态栏里一直不在线。按后面的排错表查。

上线以后再往下做。

## 第 8 步：「本群ID」→ 授权群和管理员

插件要知道哪些群能看到联盟市场的价格（授权群），谁能用管理命令（管理员）。这两样都要填 ID，ID 用「本群ID」查。

1. 在测试群的输入框里输入 `@`，**从弹出的列表里选机器人**（自己手打名字不算 @），再输入 `本群ID`，发送。下文的「@机器人 发 xxx」都是这样操作。
2. 机器人回 3 条消息：
   - 第 1 条是说明，里面写着「授权群一栏填：本群 ID（下一条）」「管理员一栏填：qq: 加上你的 ID（最后一条）」「本群现在：未授权」；
   - 第 2 条只有**本群的 ID**；
   - 第 3 条只有**你的 ID**。
   
   长按（手机）或选中（电脑）就能复制。这些 ID 是一长串字母和数字，**不是群号、也不是 QQ 号**。

   「管理员一栏填：qq: 加上你的 ID」的意思是：管理员一栏里可以在 ID 前面加上 `qq:`，也可以不加，两种写法一样。**不要把「qq: 加上」这几个字抄进去**，只复制第 3 条的 ID。
3. 打开 Koishi 控制台 → 插件配置 → **eve-market**（本插件）→ 「权限」这一组：

   | 配置项 | 填什么 |
   |---|---|
   | `admins`（管理员） | 点 `admins` 右边的「**添加项目**」，在新出现的框里粘贴**第 3 条（你的 ID）** |
   | `allowedGroups`（授权群） | 点 `allowedGroups` 右边的「**添加行**」，在新的一行里填：群 ID = **第 2 条（本群的 ID）**，备注 = `测试群`，启用打勾 |

   测试群要不要放进授权群：想在测试群里看到联盟市场的价格、用「市场状态」，就放进去。[测试步骤.md](测试步骤.md) B 部分会先不放、再放，对比一下。
4. 保存：点右上角的勾号图标「**重载配置**」（鼠标移上去会显示这个名字），或者按 Ctrl+S。本插件重载几秒钟，不影响别的插件。
5. 检查管理员填对了没有：@机器人 发 `帮助 样式自检`。回复的标题是「**样式自检（管理员）**」就对了；回的是帮助总表（标题「EVE 市场助手」），说明 ID 没填对，回到第 2 点重新复制第 3 条。
6. 把测试群放进了授权群的话，再 @机器人 发一次 `本群ID`，第 1 条应该变成「本群现在：已授权」。

注意：

- **同一个人在不同群里、在私聊里的 ID 可能不一样**（待实测）。第 1 条最后一句「管理员建议填私聊里拿到的 ID」也是因为这个。所以管理员一栏的规则是：**群里拿到的 ID 和私聊里拿到的 ID 都加进去**，各占一项。能私聊的话，私聊机器人直接发 `本群ID`（不用 @），回 2 条，第 2 条是你在私聊里的 ID，再「添加项目」加一项。要在别的群里也当管理员，就在那个群里再发一次，把那里的「你的 ID」也加进去。
- 第 1 条里如果多了一行「你的跨群 ID：…」，把它也填进管理员，这样在所有群和私聊里都算管理员（待实测）。
- **重新创建机器人以后，所有 ID 都会变**，授权群和管理员要重新填。

## 第 9 步：样式自检

QQ 客户端对 Markdown、按钮、图片的显示有些地方没有文档写明，上线前要在测试群里看一遍。

1. 管理员在测试群里 @机器人 发 `样式自检 1`。机器人发 4 条测试消息（1-1 到 1-4），每条开头都写了「正常」是什么样子。
2. 看完以后 @机器人 发 `样式自检 2`，再发最多 4 条（2-1 到 2-4）。
3. 每一页最后一条写了回报的格式，照这个格式把结果告诉开发者。
4. 有不正常的地方，开发者改好以后发一个补丁版本，控制台里不用改任何设置。

「样式自检」只回应管理员，在哪个群都能用（测试群不用是授权群）。别人发了没有任何反应。

怎么判断每一项、怎么回报，详细写在 [测试步骤.md](测试步骤.md) 的 B 部分。

## 第 10 步：提审、发布上线

基础的查价功能通过 [测试步骤.md](测试步骤.md) B 部分以后就可以提审，不必等全部功能做完。是否还需要「提审」、要交哪些材料，以开放平台实际的界面为准（待实测）。

提审前对照这张清单：

| 项目 | 怎么做 |
|---|---|
| adapter-qq 的 `sandbox` | 确认是**关**的 |
| 名称、头像、简介 | 一起审核，上线以后每月只能改 5 次，一次想好。不要用 CCP 的图标，不要写「EVE 官方」之类的字样 |
| 资料卡预览 | 在预览里看一眼资料卡上会不会显示认证主体（例如公司名）（待实测） |
| 自测报告 | 平台有模板的话，用 [测试步骤.md](测试步骤.md) B 部分的表格和截图来填 |
| 使用范围 | 建议选「白名单」：只放联盟的群（数量上限待实测）。联盟价格无论如何都只在控制台「授权群」里显示 |
| IP 白名单 | 见下面一节 |
| 「/」指令面板 | **第一次提审时不配**，上线以后再说（见第 11 步） |

提交以后要等审核。**审核通过后，要回到开放平台手动点「上线」**，不会自动上线。

### IP 白名单

开放平台说明里提到，提审时可能要求填 IP 白名单（是否强制待实测）。不要求就保持空着。

要填的话：

1. 查出运行 Koishi 的那台电脑的**公网出口 IP**（在那台电脑上用浏览器打开一个能显示「我的 IP」的网站）。
2. 填进开发设置的 IP 白名单。
3. 那台电脑如果开了代理或 VPN：要让 `api.bot.qq.com`、`bots.qq.com` 直连、不走代理，否则 QQ 看到的 IP 和白名单不一样。
4. **以后这个 IP 变了，机器人会整个掉线**（日志里能看到错误码 11298）。到时候回开发设置更新白名单。

### 上线以后：拉进联盟的群

1. 使用范围选了白名单的，先在开放平台把联盟的群加进使用范围。
2. 请那个群的群主或管理员把机器人拉进群（只有群主或管理员能拉）。
3. 在那个群里 @机器人 发 `本群ID`，把群 ID（第 2 条）加进控制台的「授权群」，保存（右上角的勾号「重载配置」，或 Ctrl+S）。
4. 在群里发一次公告（模板见 [从旧插件迁移.md](从旧插件迁移.md)）。

## 第 11 步（可选，上线以后）：「/」指令面板

配好以后，群友点输入框里的「/」就能选命令，不用记命令名。

- **上线以后再配**。在开放平台的「发布设置 → 功能配置 → 指令配置」之类的地方（位置待实测）。这一项属于提审内容，**每改一次都要重新审核**，所以第一次提审时不配。
- 面板只是把文字填进输入框，**不会自动发送**。需要后面接物品名的命令，「填入」的内容末尾留一个空格。
- 插件会自动去掉开头的 `/`，所以面板填进去的 `/查价 乌鸦级` 也能用。
- 名称不超过 14 个字。管理命令和「本群ID」不放进面板。

建议的内容：

| 名称 | 填入 | 说明 |
|---|---|---|
| 查价 | `查价 ` | 查一个物品的价格 |
| 批量查价 | `批量查价 ` | 粘贴清单或装配估总价 |
| 走势 | `走势 ` | 价格走势图 |
| 搜索 | `搜索 ` | 搜索、相关物品 |
| 翻译 | `翻译 ` | 中英文名对照 |
| 入侵 | `入侵` | 当前入侵 |
| 势力图 | `势力图` | 欧服势力图 |
| 联盟势力图 | `联盟势力图` | 联盟影响力图 |
| 战报 | `战报 ` | BR 截图 |
| 服务器状态 | `服务器状态` | 在线人数、开服时间 |
| 制造 | `制造 ` | 制造成本和时间 |
| 制造比价 | `制造比价 ` | 比较几个制造地点 |
| 反应 | `反应 ` | 反应成本 |
| 帮助 | `帮助` | 使用说明 |

## 关于「接收群内全部消息」

群主可以在手机 QQ 里给机器人打开「接收群内全部消息」。**本插件不需要它**，保持关闭就行。

如果哪个群打开了：本插件配置「基本」里的 `requireAt`（群里只处理 @机器人 的消息）保持打开（默认就是打开的），这样不 @ 机器人的消息不会被处理，也不会和群里的其他机器人重复回复。

## 常见问题

| 现象 | 可能的原因 | 怎么办 |
|---|---|---|
| 日志里有带 `getAppAccessToken` 的警告，机器人不上线 | AppID 或 AppSecret 填错；或者 AppSecret 在开放平台上重置过 | 重新复制 AppID；AppSecret 找不到就在开发设置里重置，把新的填回 adapter-qq，保存（右上角的勾号「重载配置」，或 Ctrl+S） |
| 机器人不上线，日志里有错误码 **11298** | 开发设置里填了 IP 白名单，但 Koishi 那台电脑的公网 IP 不在里面 | 按「IP 白名单」一节更新白名单；不需要白名单的话清空它（待实测） |
| 机器人原来好好的，**突然全都不回复** | 多半是公网 IP 变了（日志里有 11298） | 去开发设置更新 IP 白名单 |
| 机器人在线，但在群里 @ 它没有任何反应 | `intents` 没勾 `USER_MESSAGE`；或者机器人不在这个群里；或者还没上线、这个群不是测试群；或者手打了 @ 名字，没有从列表里选 | 依次检查。都没问题时，可以**临时**把 adapter-qq 的 `sandbox` 打开试试（只在测试群里没反应时试，待实测），**上线前一定关回去** |
| 日志每隔几秒报一次 `invalid intents` | adapter-qq 的 `intents` 一项都没勾 | 勾上 `USER_MESSAGE`，保存 |
| 断网恢复以后，日志每分钟报一次 `AccessToken无效或过期`（错误码 11244 或 40011027），机器人一直不上线 | adapter-qq 4.14.0 的问题：断网时没换到新的令牌，恢复以后也不会自己重新取 | 本插件的看门狗（控制台「基本」里的 `qqWatchdog`，默认打开）在机器人连续 10 分钟不在线时会自动重启 adapter-qq，一般不用管。想马上恢复：在控制台把 adapter-qq 停用再启用。「市场状态」里「官方机器人」一行能看到自动重启过几次 |
| @ 后面的名字前出现反斜杠，例如「@\[军团\] 名字」 | 群友的名片里有方括号这类 Markdown 符号，QQ 在显示 @ 时自己加了反斜杠。插件只发了 @ 的 ID，名片是 QQ 填进去的 | 插件这边改不了，不是故障；名片里去掉方括号就不会出现 |
| 别的插件回复了，本插件没反应 | 本插件没启用，或者还在加载 | 在插件配置里确认 eve-market 是启用的；看日志里本插件的报错 |
| 回复「数据加载中，请稍后再试」 | 插件刚启动，物品数据还没加载完 | 等几秒再发 |
| 官方机器人回答了旧插件的命令（例如 `ojita`），或者同一条消息回了两次 | 旧插件没有设过滤器 | 按 [从旧插件迁移.md](从旧插件迁移.md) 第 2 步设过滤器。（发战报链接时 LLBot 也截一张图，是旧的 eve-br 还开着，属正常，停用旧插件以后就没有了） |
| 私聊机器人没有反应 | 私聊（开放平台叫「单聊」）还没开通 | 见第 5 步；不影响群里使用 |
| 「市场状态」「市场授权」发了没反应 | 不是管理员；或者在一个**不是授权群**的群里发的 | 这两个命令只在私聊或授权群里回应。把 ID 填进管理员、把群加进授权群 |
| 「样式自检」发了没反应 | 不是管理员 | 把「本群ID」第 3 条的 ID 填进管理员 |
| 消息全是纯文字，没有加粗和按钮 | Markdown 被 QQ 拒绝，插件自动改发纯文字 | 管理员发「市场状态」，看「消息」一行；把日志里那段时间的错误码告诉开发者 |
| 按钮点了没反应，或者点完输入框里没有 @机器人 | QQ 客户端的显示问题 | 把「样式自检 1」的结果告诉开发者。临时办法：本插件「显示」里的 `clickable` 改成「不带」，消息里会改写成编号和完整命令 |
| 拉不了机器人进群 | 不是群主或管理员；或者机器人还没上线，这个群不是测试群；或者这个群不在使用范围的白名单里 | 请群主或管理员拉；上线前只能拉进测试群 |
| 重新创建了机器人 | 新机器人的 AppID、AppSecret、所有群和用户的 ID 都变了 | 重新做第 6 步和第 8 步 |

## 安全说明

- AppSecret 只填在 Koishi 控制台的 adapter-qq 里，控制台里显示为密码框。
- 不要把 AppSecret 写进任何文件、截图或聊天。需要开发者帮忙时，只发日志里的报错，不发配置页的截图。
- 怀疑泄露了就在开发设置里重置，旧的立即失效。
- 「本群ID」显示的 ID 不是密码，但也不要发到公开的地方。
