# 工业公式

「制造」「制造比价」「反应」怎么算材料、时间和安装费用。公式写在 `src/core/industry/formulas.ts`（材料、时间、费用）和 `src/core/industry/modifiers.ts`（建筑、改装件、安全等级），加成数值全部来自插件数据 `industry.json`，代码里不写死。

- 当前公式版本：`FORMULA_REVISION = 2`（每个计算结果都带着它）。0.0.5 改成 2：税按活动分开（制造税、反应税、提炼税），新增自动挑建筑、建筑能力判断、拆到原料和炼金术；同一个建筑、同一个产品、写了 `建筑:` 时，材料、时间、费用的数字和版本 1 完全一样。
- 写法和 eve-ref 的工业计算器一致（它的测试数值来自游戏截图，MIT-0 许可）；下面的「黄金向量」就是用它的数值做的测试。
- 标着「**待核实**」的是还没有在游戏里逐一确认的规则或常量。核实以后只改常量或配置默认值，同时改 `FORMULA_REVISION` 和这份文档。

## 名词

| 名词 | 意思 |
|---|---|
| 流程 | 蓝图跑一次。`*1000` 这种写法是产品数量，流程数 = ⌈数量 ÷ 每流程产出⌉；`10流程` 直接指定流程数 |
| 工作 | 在工业窗口里开一次工作。一般一个工作就包含全部流程（例外见「T2 拆成多个工作」） |
| ME / TE | 蓝图的材料效率（0–10）和时间效率（0–20）。反应配方不能研究，ME、TE 一律按 0 |
| S | 建筑加成（乘数，例如索迪约材料 0.99、时间 0.70、费用 0.95）；无建筑 = 1 |
| R | 改装件加成（乘数）；没有生效的改装件 = 1 |
| EIV | 预估物品价值：按 ME 0 的材料数量 × ESI 的调整价（`/markets/prices` 的 `adjusted_price`） |
| SCI | 星系的星系成本指数（`/industry/systems`，制造用 `manufacturing`，反应用 `reaction`） |

## 安全等级

按星系的真实安全等级（数据里 6 位小数）分类：

| 分类 | 条件 |
|---|---|
| 高安 | ≥ 0.45 |
| 低安 | > 0 且 < 0.45 |
| 00 | ≤ 0；虫洞星域（ID ≥ 11000000）和波赫文不管数值都算 00 |

显示时统一四舍五入到 1 位小数，但 0 和 0.05 之间显示 0.1（游戏里的显示规则，**待核实**）。分类用真实值，显示用取整后的值，两者不会互相矛盾：0.45 显示 0.5 是高安，0.03 显示 0.1 是低安，不会出现「0.0 · 低安」。分类边界 0.45 和 0 **待核实**。

## 修正

### 建筑 S

`S = 建筑数据里这种活动的加成 ?? 1`，三种：材料 `me`、时间 `te`、费用 `cost`。例子（来自数据）：

| 建筑 | 制造 材料 / 时间 / 费用 | 反应时间 |
|---|---|---|
| 莱塔卢 Raitaru | 0.99 / 0.85 / 0.97 | — |
| 阿兹贝尔 Azbel | 0.99 / 0.80 / 0.96 | — |
| 索迪约 Sotiyo | 0.99 / 0.70 / 0.95 | — |
| 塔塔拉 Tatara | — | 0.75 |
| 阿塔诺 Athanor、空堡、铁壁、星城 | 没有加成 | 没有加成 |

- 「无建筑」（NPC 空间站、`建筑:无`）时 S = 1，改装件也不算。
- 数据里 `highsec` 为 false 的建筑（索迪约、星城）配置在高安地点时报告配置问题。
- 反应只能在精炼厂（阿塔诺、塔塔拉）做；配置成别的建筑（包括建筑类型「无」和 NPC 空间站）做反应时报告，这一行的「反应」不生效。命令里给反应写 `建筑:无` 时不计算，重新问建筑。精炼厂能不能做制造**待核实**，目前不拦。

### 建筑能做什么（能力）

0.0.5 起，哪种建筑能造哪种产品，不再只看「是不是精炼厂」，而是看游戏数据里的**建筑服务表**（eve-cn-slang 的 `industry.json` 里的 `services`，从 SDE 生成，插件里不写死物品清单）。规则在 `src/core/industry/capabilities.ts`：

1. 每个服务装备（屹立制造厂、旗舰级船坞、超级旗舰级船坞、三种反应堆、提炼模块）记着：能造哪些分组和大类、能装在哪些建筑上（建筑类型或分组）、在哪些安全等级能用（高安 / 低安 / 00）。
2. 产品要的服务 = 活动对得上、并且分组或大类被覆盖的服务。
3. 建筑实际有的服务 = 能装在这座建筑上 + 在这个安全等级能用 + 按「用途」和开关算作装了：
   - 屹立制造厂、旗舰级船坞：用途含制造就算装了（旗舰级船坞不能在高安用，所以高安的阿兹贝尔造不了航母，卡片写「高安不能造旗舰」这类原因）；
   - 超级旗舰级船坞：只有勾了「有超旗舰船坞」才算（只有索迪约装得上，只在 00 能用；真实游戏里还要主权升级，插件不单独判断，开关就代表它）；
   - 反应堆：用途含反应就算装了。三种反应堆（分别管 428/429/4932、974、712/4096 几个分组）都当作装了，按反应堆类型筛选以后再做；
   - 提炼：用途含提炼就算装了。
4. 阿兹贝尔、索迪约、铁壁、星城（含各势力的铁壁和 Palatine 星城）因为类型对得上，自动有旗舰级船坞；不用在控制台填。
5. NPC 空间站和 `建筑:无` 只有屹立制造厂这一个服务，所以旗舰里只能造货舰（513）、跳货（902）、逆戟鲸级 Orca（941）；长须鲸级 Rorqual（883）要旗舰级船坞。这一条的依据是 SDE 的装配线，**待游戏里核实**。
6. 一座建筑都没配的地点，按「制造厂」的能力算。
7. 数据里没有服务表（旧数据），或者没有任何服务覆盖这个产品（目前只有分组 1194「Special Edition Commodities」）时，不筛选，照旧能算。

地点能不能造 = 地点里任一座建筑能造。造不了的地点不列出来，卡片写「另有 N 个地点造不了（需要旗舰级船坞）」；写了造不了的地点时回答原因并给能造的地点按钮；本群没有任何能造的地点时回答「没有配置」并写明需要什么。

### 自动挑建筑

没写 `建筑:`、地点里能造这个产品的建筑有 2 座以上时，每座建筑都完整算一遍（材料 + 安装费 + 税 + 其他费用，和结果卡上的预计总成本是同一个数），按下面的顺序挑第一名（`src/core/industry/pick.ts`）：

1. 预计总成本，从低到高（取整到 1 ISK 后一样算一样，免得排序看输入顺序）；
2. 一样的话，时间（未计技能，各座建筑可以直接比），从短到长；
3. 再一样，勾了「默认建筑」的在前；
4. 再一样，表格里靠前的在前。

- 价格只取一份：每座建筑用同一份材料报价，不多发请求。市场价缺的材料，排序时用 ESI 的调整价顶上，只用来排序，不改结果卡上的数字；一个价格都没有时全部用调整价排序，卡片的总成本照旧写「不完整」，不写 0。
- 地点只有一座能造的建筑时照旧写「该地点唯一」，不写「自动选择」。
- `建筑:无`、`改装:无`、`税:` 都参与：所有候选用同样的条件算。
- 「制造比价」：每个地点都这样挑一座，每行写挑中的建筑，「详情」按钮带着这座建筑。
- 「高级」选建筑那一步：造得了的建筑各算一遍，预计总成本最低的排第一、标「推荐」，每座写预计总成本；造不了的建筑不列，在底下说明有几座。

### 改装件 R

```
R = 1 + Σ（这条效果的百分比 ÷ 100 × 改装件在这个安全等级的倍率）
```

- 一个改装件的每条效果是「活动、种类（材料/时间/费用）、目标过滤器、百分比」。只有活动和种类对上、并且产品的大类或分组在过滤器里（过滤器为空表示这个活动的所有产品）的那条才计入。同一个改装件对不同产品的百分比可能不同，例如 Thukker 改装件对旗舰组件、高级旗舰组件的材料加成是 -3.7，对建筑和其他组件是 -2。
- 安全等级倍率来自数据，例如工程改装件 高安 1.0 / 低安 1.9 / 00 2.1；反应改装件没有高安值，表示在高安不生效，卡片上标「在此安全等级不生效」。
- 尺寸要和建筑能装的一致（中型 / 大型 / 超大型），不一致的报告配置问题、不计入。
- 多个改装件**相加**（和 eve-ref 一致；游戏里是否确实相加**待核实**，实际上很少有两个同时对一个产品生效）。

例：00 的索迪约装超大型舰船制造效率 I，造乌鸦级：R材料 = 1 + (-2 ÷ 100 × 2.1) = 0.958，R时间 = 1 + (-20 ÷ 100 × 2.1) = 0.58。卡片上写「材料 -4.2%，时间 -42%」。

## 材料（每个工作）

```
系数 = (1 − ME ÷ 100) × S材料 × R材料            反应：ME 项 = 1
数量 = max(流程数, ⌈round2(流程数 × 基础数量 × 系数)⌉)
round2(x) = 四舍五入到 2 位小数
```

- 先保留 2 位小数再向上取整，是为了消掉浮点误差（同 eve-ref；游戏里的取整顺序**待核实**）。
- 每个流程至少 1 个：例如核心温度调节器每流程 1 个，10 流程算出 8.54 → 9 个，但最少要 10 个。
- 基础模式（ME 0、无建筑、无改装件）时系数 = 1，数量就是 流程数 × 基础数量。

例：乌鸦级 ME 10、00 索迪约、超大型舰船制造效率 I，系数 = 0.9 × 0.99 × 0.958 = 0.853578，三钛合金 5,200,000 × 0.853578 = 4,438,605.6 → **4,438,606**。

## 时间（每个工作）

```
时间（秒）= 四舍五入( 流程数 × 基础时间 × (1 − TE ÷ 100) × S时间 × R时间 × 技能系数 )    反应：TE 项 = 1
```

- 卡片上的主数字不计技能（技能系数 = 1）。游戏里是四舍五入、向上还是向下取整**待核实**。
- 卡片上时间分行写，样子像游戏里的「项目周期修正值」：第一行是主数字（标「未计技能」；反应写「每流程 … · 共 …」），下面缩进列出各项修正，最后一行「满技能约 …」。修正行依次是「蓝图 TE 20 -20%」（只有制造且 TE 大于 0 才有）、「技能和植入体（按技能全 5 级，不算植入体）-32%」（制造 -32%，反应 -20%，每张卡片都有）、「已安装的改装件 -x%」（改装件时间加成合计不为 0 才有）、「建筑持有加成 -x%」（建筑有时间加成才有）。各行只写自己那一项，乘数相乘得到主数字（满技能那行再乘技能系数）。
- 另算一次「满技能约 …」：制造 0.68（Industry 每级 -4%、Advanced Industry 每级 -3%，都按 5 级），反应 0.80（Reactions 每级 -4%）。这两个值在 `src/constants.ts`（`MAX_SKILL_MANUFACTURING_MULT`、`MAX_SKILL_REACTION_MULT`），**待核实**。T2 专精技能和工业植入体不计。
- 多个工作时是一条生产线连续做完的总时间。

例：乌鸦级 TE 20、00 索迪约、超大型舰船制造效率 I：18,000 × 0.8 × 0.7 × 0.58 = 5,846.4 → **5,846 秒**。

## 安装费用（每个工作）

```
EIV       = 取整( 流程数 × Σ 调整价 × ME0 基础数量 )
星系成本指数费 = 取整( EIV × SCI )
加成       = 取整( 星系成本指数费 × S费用 × R费用 × (1 + 星系加成% ÷ 100) − 星系成本指数费 )     负数 = 折扣
设施税     = 取整( EIV × 设施税% ÷ 100 )
SCC 附加费 = 取整( EIV × SCC% ÷ 100 )
其他费用   = 取整( EIV × 其他费用% ÷ 100 ) + 每个工作的其他费用 ISK
合计       = 星系成本指数费 + 加成 + 设施税 + SCC 附加费 + 其他费用
```

- 取整到 1 ISK，.5 远离 0（同 eve-ref；游戏里的取整方式**待核实**）。
- 卡片上费用分行写，金额一律取整：「基础物品成本」（EIV）、「星系成本指数 x.xx%」（= 星系成本指数费 + 加成，建筑的费用加成已经算进这一行）、「设施税」、「SCC 附加费」、「其他费用」（为 0 时不显示），最后是「预计总成本」。星系成本指数取不到时不写「星系成本指数」这一行（不会写成 0），原因见警告。
- EIV 用 ME 0 的数量，和 ME、建筑、改装件无关。某个材料没有调整价时 EIV 跳过它，卡片警告「部分材料缺少调整价，安装费偏低」。
- 星系不在 `/industry/systems` 里时星系成本指数按 0 算并警告（CCP 有没有最低指数**待核实**）。
- **星系成本指数的精度**：ESI 给的指数比游戏界面显示的位数多（例如界面显示 7.46%，ESI 是 0.0746108842…）。拿界面上的数字手算会差 1–2 ISK，这是正常的。
- Alpha 克隆的额外税（0.25%，**待核实**）不计。

### 设施税和其他费用

- 游戏里建筑主人设的税按活动分开。控制台建筑表有三列：「制造税」（`facilityTaxPct`，就是 0.0.4 的「设施税」，键名没变）、「反应税」（`reactionTaxPct`）、「提炼税」（`reprocessingTaxPct`）。制造用制造税，反应用反应税，炼金的提炼用提炼税（见「炼金术」）。需求里说的「Facility Tax」「Structure Tax」就是它们。
- 回落：反应税**留空 = 制造税**（所以已有的配置不用重填，结果和 0.0.4 一样）；填 0 就是 0。提炼税留空 = 0。
- 命令里写 `税:1.5%` 时用命令里的值（拆到原料时只改成品这一步，见「拆到原料」）。
- 「无建筑」（NPC 空间站）时用控制台「工业」分组的「NPC 空间站设施税」（`npcFacilityTaxPct`，默认 0.25%，**待核实**）。
- 控制台建筑表的「建筑类型」有两个特殊写法：
  - 「无」：这一行没有建筑加成，不能装改装件、不能做反应，设施税用这一行自己填的；
  - 「NPC」（也可以写 NPC 空间站、station）：NPC 空间站，没有建筑加成、不能装改装件、不能做反应，设施税一律按「NPC 空间站设施税」算，这一行填的设施税不生效（会在「市场状态」里提示）。
- 制造时命令里写 `建筑:无`、或者这个地点一座建筑都没配，也按 NPC 空间站算设施税。
- 联盟额外收的钱不是游戏里的税，用建筑表的「其他费用」：`extraFeePct`（EIV 的百分比）和 `extraFeeIsk`（每个工作固定 ISK），卡片上的名字是 `extraFeeLabel`。
- SCC 附加费是控制台「工业」分组的 `sccSurchargePct`（默认 4%，和 eve-ref 的游戏内测试一致；现在的值**待核实**）。

## 反应

- 没有 ME、TE（配方不能研究）。
- 精炼厂加成来自数据：塔塔拉反应时间 0.75，阿塔诺没有加成。
- 税用建筑的「反应税」；没填就是制造税。
- 反应改装件：低安 1.0、00 1.1，高安不生效；高安不能进行反应。
- 安装费用用星系成本指数的 `reaction`，其余和制造相同。

## T2 拆成多个工作

数据里蓝图的 `maxRuns` 是蓝图**拷贝**的单次流程上限；它是否也限制用原图开的工作**待核实**。在核实之前：

- 只对 T2 产品（发明出来的拷贝）在流程数超过上限时拆成多个工作：若干个满的加一个余数，例如上限 10、25 流程 → 10 + 10 + 5。
- 材料按每个工作分别计算再相加（取整发生在每个工作里），时间、安装费用也按工作分别算再相加；其他费用的固定 ISK 每个工作收一次。
- T1 产品按原图算，一个工作。

这条规则只在 `splitJobs` 一个函数里，核实后改那一处。

## 不写 ME/TE 时用什么

| 情况 | ME / TE |
|---|---|
| 基础参考（`制造 乌鸦级`，不写地点） | 0 / 0 |
| 写了地点（`制造 乌鸦级 XX-1`） | 地点表的「默认 ME/TE」（默认 10 / 20），卡片上标「（地点默认）」 |
| T2 产品 | 2 / 4（发明出来的拷贝常见的值），卡片上标「（T2 常见值）」；地点的默认值一般是 10 / 20，发明拷贝达不到 |
| 制造比价 | 10 / 20；T2 产品 2 / 4 |
| 反应 | 没有 ME/TE，写了也不用 |
| 拆到原料的中间产品（组件） | 10 / 20（`CHAIN_COMPONENT_ME_TE`），反应 0 / 0；成品那一步照上面的规则 |

## 卡片上的数字

| 卡片上 | 公式里 |
|---|---|
| 材料成本 | Σ 材料单价 × 数量（每种材料先四舍五入到 0.01 ISK）。单价按控制台「材料按哪个市场、哪个价格」，默认 Jita 出售价；没有价格的材料不计入，总成本标「不完整」 |
| 基础物品成本 | EIV |
| 星系成本指数 | 星系成本指数费 + 加成 |
| 设施税、SCC 附加费、其他费用 | 同名的几项；其他费用为 0 时不显示，名字是建筑表的「其他费用的名称」 |
| 预计总成本 | 材料成本 + 基础物品成本以外的费用合计（星系成本指数、设施税、SCC 附加费、其他费用） |
| 制造时间 / 反应时间 | 主数字不计技能；下面的修正行和「满技能约」见上面「时间」一节 |
| 成品价值 | 产出数量 × 成品单价（控制台「成品按哪个市场、哪个价格」，默认 Jita 出售价） |
| 预计利润 | 成品价值 − 预计总成本 − 成品价值 × 销售税和经纪费%（控制台 `sellFeesPct`，默认 0，卡片注明「未计销售税和经纪费」） |
| 利润率 | 预计利润 ÷ 成品价值 |

- 某个材料没有价格、又配置了「回退市场」时改用回退市场的价格，那一行标 †。材料市场整个不能用时（例如玩家建筑市场授权异常），卡片写一行原因，整体改用回退市场；没配回退市场时成本标「不完整」。
- 星系成本指数、调整价暂时取不到时照样出结果，卡片写明哪一项没算进去；用的是更新失败前的旧数据时，页脚的更新时间后面标「（缓存）」。
- 制造比价：每个地点用自动挑中的建筑（见「自动挑建筑」）、它的改装件、税和其他费用，材料价格各地点相同，按预计总成本从低到高排，标出最低（💰）和最快（⚡）。命令里写了 `改装:无` 或 `税:1.5%` 时每个地点都这样算，卡片上方写明，「详情」按钮和编号回复也带着，详情和比价的那一行数字一致。

## 拆到原料

`制造 帕拉丁级 XX-1 拆到原料`。引擎在 `src/core/industry/chain/`，入口是 `IndustryService.chain()`，结果是单独的 `ChainResult` 类型，不改普通「制造」的结果。

### 分层

材料按结构分层，不写物品清单（`chain/layers.ts`）：

| 层 | 是什么 | 默认 |
|---|---|---|
| 高级反应 | 反应产物，材料里有别的反应产物 | 造 |
| 低级反应 | 反应产物，材料里没有别的反应产物（月矿元素之上的第一层，聚合物、生化也自然归在这里） | 造 |
| 组件 | 有制造蓝图的其余材料 | 造 |
| 其他 | 有制造蓝图的：船（大类 6，T1 船体）、燃料块（分组 1136）、R.A.M.（分组 332）、T2 物品对应的 T1 原型装备 | 买 |
| 原料 | 没有蓝图的：月矿元素、矿物、冰产物、行星材料 | 永远买 |

「继续拆」按钮 / `其他:造` 就是把「其他」改成造。

### 算法

1. 顶层（成品）：地点、ME/TE、建筑的规则和普通「制造」一样，能力检查也一样；没有可用地点时整条链按「无建筑」算，不算安装费，卡片注明。
2. 展开成图：从成品开始，每个材料按「这一层造还是买、有没有蓝图、有没有能造它的地点」决定是不是一个工作；不是的就是叶子（直接买）。遇到环时这条边改成买并警告。
3. 按「消费者在前、生产者在后」的顺序一层一层累加需求。
4. **整批**：中间产品的流程数 = ⌈需求 ÷ 每流程产出⌉，实际产出可能多于需求，多出来的写「多出 N 个」，**成本不扣**。两个上层共用同一个中间产品时，先把需求加起来再取整，只取整一次。例：需求 250、每批 200 → 2 批，多出 150。
5. 中间产品的 ME/TE：组件 ME 10 / TE 20，反应没有；不按 T2 拷贝上限拆成多个工作。
6. 每个工作自己挑建筑：
   - 制造：在命令写的地点里，过滤出造得了的建筑，按「自动挑建筑」的规则挑；
   - 反应：命令写的地点里有能反应的精炼厂就用它；没有就依次试控制台的「默认反应地点」、本群表里第一个能反应的地点（总览卡写「反应在 … （… 没有精炼厂）」）；都没有时这一项改成直接买并写警告。
7. 安装费和税：每个工作用自己建筑的税（制造税 / 反应税）。命令里的 `税:` **只改成品这一步**。
8. 价格：整棵树的物品合成一份清单，材料市场只请求一次（成品市场另取一次，回退市场只补缺价格的），指数和调整价各取一次。最多等 `CHAIN_QUERY_DEADLINE_MS = 12000` 毫秒，没赶上的记为缺价格、结果标不完整（请求在后台接着做完，进缓存，下次很快）。涉及的物品超过 `CHAIN_MAX_TYPES = 200` 种时直接失败，提示可以少拆几层。
9. 合计：预计总成本 = 所有叶子的材料价 + 所有工作的安装费和税 + 炼金的提炼税。每一层同时算「自己造」和「直接买约」（= 这一层所有东西 需求量 × 市场单价）两个数，方便比较；这一层没有被用到时（例如组件直接买，下面的反应用不到）写「（…直接买，没有用到）」。
10. 利润：成品价值 − 预计总成本 − 销售税和经纪费；有价格缺失时不算利润，写「价格不全，利润不计算」。
11. 时间：每个工作各自的时间；每一层把这一层所有工作的时间**加起来**（一条生产线串行），不算几层同时做的最快时间；不计技能。
12. 发明成本不计入。

### 总览卡、分层明细、原料清单

总览卡是默认也是唯一自动发的一条；明细和原料清单是按钮，每次点都是一条新命令，有新的回复额度（群里 4 条、私聊 3 条），所以不会超限，手机上也不刷屏。每条消息不超过 3,500 字，最多拆 3 条，按钮最多 4 行。

## 炼金术

低级反应（月矿原料）有另一条路：先造对应的「粗糙的…」产物（17 种，数据里 `reprocessing` 表），再拿去废料提炼，得到想要的反应产物和一些副产品。

- **提炼率**：`50% × (1 + 2% × 废料处理技能等级)`，默认 5 级 = 55%（控制台 `scrapmetalLevel`）。常量 `SCRAP_BASE = 0.5`、`SCRAP_PER_LEVEL = 0.02`（`src/constants.ts`）。
- **没有别的加成**：建筑、改装件、植入体、普通提炼技能对这 17 种都不生效（加成只作用于矿石和冰；数据里这 17 种没有专用提炼技能，2014 年 CCP 改版说明和后来的攻略数字也对得上）。以后数据里这 17 种出现专用提炼技能（属性 790）时，这一种不提供炼金，「市场状态」报「X 有专用提炼技能，炼金术不计算这一种」。
- **产出**（默认逐个取整）：每个粗糙产物提炼出 `floor(数据里的数量 × 提炼率)` 个，再乘个数。`REPROCESS_ROUNDING = 'per-unit'`（保守）；另一种是整批一起取整（`'batch'`）。
- **要做多少**：需求 Q，每个粗糙产物提炼出 `perUnit` 个主产物 → 需要 ⌈Q ÷ perUnit⌉ 个粗糙产物 → 按配方每流程产出数换算成流程数。实际得到的主产物可能多于 Q，多出来的写「多出」。
- **副产品**：先抵掉**同一条路线里**同种材料要买的数量（只抵原料和直接买的东西，例如「铪 −2,375（炼金副产品）」）；抵不完的写「多出 N 个」，**不算钱**。副产品本身是要造的中间产品时，只记为多出，不抵需求。
- **提炼税**：`REPROCESS_TAX_MODE = 'isk'`：按提炼产出的**价值**（产出数量 × 材料市场单价）乘提炼税%，作为 ISK 另外收，不扣产出。提炼建筑：控制台「提炼地点」→ 命令里的地点，取那里提炼税最低的建筑；一座都没有时按 0%，并写「未配置提炼建筑，提炼税按 0 算」。产出有缺价格时提炼税为空，结果标不完整。
- **比较**（炼金术 = 自动时）：每个低级反应产物各比一次。成本 = 输入材料市场价 − 副产品抵掉本路线自己输入的部分 + 粗糙配方的安装费和税 + 提炼税；选便宜的，一样便宜选快的；另一条路线的成本差和时间差写在卡片上。`炼金` 强制走炼金；没有粗糙配方的产物仍走正常路线，卡片注明「炼金只适用于 N 种」。`正常` 完全不用炼金。
- 卡片注明「炼金按废料 55% 规则计算」。

**这三项还没在游戏里核对**（见「待核实清单」）：提炼税是收 ISK 还是扣产出；取整是逐个还是整批；废料处理的提炼率公式本身（按所有者给的公式）。
