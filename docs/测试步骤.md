# 测试步骤

在真实的 Koishi 里实测本插件的步骤，覆盖 0.0.1–0.0.3 的全部命令。分两部分：

- **A. 注册 QQ 机器人之前**：在 Koishi 控制台的「沙盒」里测。沙盒里只有纯文字，每条消息只能写一行，但命令、价格、图片都能看到。
- **B. 注册以后**：在 QQ 测试群里测。看 Markdown 卡片、按钮、图片在 QQ 上的真实样子，包括「样式自检」。

下面的「测试群」「联盟市场A」「XX-1」都是举例，换成你自己的。价格数字只是举例，看格式对不对就行。

## 准备

1. 本插件已经装好（0.0.3 或更新的版本），启用着。还没装的，先按 [从旧插件迁移.md](从旧插件迁移.md) 第 1–3 步做（备份、设过滤器，再挑群里没人说话的时候安装：安装会让 Koishi 整体重载一次）。整体的先后顺序见 [README 的「文档」一节](../README.md#文档)。
2. 打开 Koishi 控制台左边的「日志」，测试过程中出现的黄色、红色警告都记下来。
3. 走势图、战报截图要用 Koishi 的 **puppeteer** 插件。没有它时这几步的「预期」不一样，表格里分开写了。
4. 联盟建筑市场：按 [EVE授权.md](EVE授权.md) 做完授权、在「市场」表格里加好以后，带「联盟市场A」的步骤才能测；还没做的，先跳过这些步骤。
5. 下文说「保存」，都是指点配置页右上角的勾号图标「**重载配置**」（鼠标移上去会显示这个名字），或者按 Ctrl+S。配置页上没有写着「保存」两个字的按钮。详见 [控制台配置.md](控制台配置.md) 的「怎么保存」。

每一步做完，对照「预期」一栏。不符合的，记下**步骤编号**、现象、截图和当时的日志（回报方法见最后一节）。

## A. 注册之前：控制台沙盒

### A 的准备

1. 打开控制台的「插件配置」，在左边的插件列表里找到「沙盒」（sandbox）。它可能在某个分组里（分组名前面有一个小三角），点分组名展开再找。找到以后点开它，点右上角的三角图标「**启用插件**」。**整个列表里都没有沙盒，就跳过整个 A，直接做 B。**
2. 打开本插件（eve-market）的配置，在「基本」里打开 `allowSandbox`（说明是「测试用：也在 Koishi 控制台的「沙盒」里回复」），保存。
3. 点控制台左边的「沙盒」。第一次打开是空的，写着「点击「添加用户」开始体验」：
   1. 点左边栏最上面的「**添加用户**」，下面会出现一个用户（名字是英文，例如 Alice）；
   2. 选中这个用户；
   3. 点上方的「**私聊模式**」。
   
   先**不要**把自己加进管理员，A2 要看没授权时的样子。
4. 沙盒里的回复是纯文字：
   - 按钮写成一行「月度走势：@我 发送「走势 乌鸦级 月」」（最多 2 行），照着把引号里的命令发出去就是点按钮。
   - 编号写成「回复 @我 1：…」。沙盒私聊里**不用 @**，直接发 `1`。
5. **沙盒的输入框只有一行**：按回车（不管按不按 Shift）就发出去，没法换行；把记事本里好几行的文字粘贴进去，换行会被去掉，几行连成一行。所以下面每一步都只发一行。一条消息里要写几样物品时，用中文分号「；」隔开（顿号「、」、逗号「，」也行）。好几行的清单和装配，到 B 部分在 QQ 里测。

### A 测完以后

1. 把「权限 → 管理员」里沙盒的那个 ID 删掉：点那一项右边的「…」→「删除项目」，保存。
2. 关掉 `allowSandbox`，保存。
3. 沙盒里加的用户（Alice、Bob）留着不管就行。

## B. 注册以后：QQ 测试群

### B 的准备

1. 按 [QQ机器人注册.md](QQ机器人注册.md) 做完第 1–8 步：机器人在线，已经在测试群里，你的 ID 已经填进管理员。
2. **测试群先不要放进授权群**（已经放了的，在「授权群」表格里把这一行的「启用」去掉，保存）。B5 再放进去，前后对比。
3. 群里每条消息都要**真的 @机器人**：输入 `@`，从列表里选机器人，再输入命令。下表里的「@机器人 xxx」都是这个意思。
4. 点按钮只会把「@机器人 命令」填进输入框，**还要你自己点发送**。
5. 手机 QQ 和电脑 QQ 都看一眼。两边显示不一样时，分开记下来。
6. 电脑 QQ 里换行一般是 Ctrl+回车（看你的发送键设置），手机 QQ 用键盘上的换行键。

### 本群ID 和管理命令

| # | 操作 | 预期 |
|---|---|---|
| B1 | @机器人 发 `本群ID` | 3 条消息：说明（「本群现在：未授权」）、只有群 ID 的一条、只有你的 ID 的一条；长按能复制 |
| B2 | 请一个**不是管理员**的群成员 @机器人 发 `样式自检 1`、`市场状态` | **没有任何回复** |
| B3 | 管理员 @机器人 发 `市场状态` | **没有任何回复**：测试群还不是授权群，「市场状态」「市场授权」只在私聊或授权群里回应。这是正常的 |

### 样式自检

管理员在测试群里 @机器人 发 `样式自检 1`，看完再发 `样式自检 2`。每条测试消息开头都写了「正常」是什么样子，照着看。

| # | 看哪一条 | 正常的样子 |
|---|---|---|
| 1-1 | Markdown 格式 | 列表前面是圆点不是减号；嵌套的一行往右缩进；`258,400,000 ISK` 是灰底（或等宽）的字，两边没有小撇号；粗体两边没有星号；引用左边有竖线（或整行换了颜色），看不到 `>`；只换一行的两行紧挨着；看不见的空格那一行空出一行；最下面有一条横线，看不到 `***` |
| 1-2 | 按钮 | 消息里写了应该有几行按钮、每行几个，数一数对不对；行和行之间没有空行；第 1 行第 1 个是蓝色的；点任意一个，输入框里出现「@机器人 命令」，不会自动发送 |
| 1-3 | 可点文字 | 写法 A、写法 B 各点一下。正常：输入框里是「@机器人 帮助」。只有「帮助」没有 @ 记成「不带 @」；出现一串 `%` 记成「编码」；看到 `<` 或者点不动记成「不正常」 |
| 1-4 | 回报格式 | 照这条写的格式回报（私聊里这一段并在 1-3 的最后） |
| 2-1 | 长图下面的说明 | 那行说明文字紧贴在图片下面，和图片是同一条消息 |
| 2-2 | 引用回复 | 这条消息引用了你刚发的「样式自检 2」（上面有一个小框） |
| 2-3 | @ 提醒（私聊里没有这一条） | 这一行开头是「@你的名字」，你收到了一条 @ 提醒 |
| 2-4 | 长消息和长图 | 长消息一直能看到最后一行「——样式自检 2-4 到这里结束——」，没有被截断；长图点开以后从上到下能看清 1 到 8 |

长图没发出去时，2-2 那条消息前面会写明「长图没有发出去」，这时 2-1、2-4 的图片部分记成不正常。

**怎么回报**：第 1 页最后一条、第 2 页最后一条都写了格式，例如：

```
1-1 正常 / 1-2 不正常（第 2 行没显示）/ 1-3 A 不带 @、B 正常
2-1 正常 / 2-2 不正常（没有引用）/ 2-3 正常 / 2-4 长消息正常、长图看不清
```

手机和电脑不一样时，写两行，前面注明「手机」「电脑」。不正常的项附一张截图。
