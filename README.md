# koishi-plugin-eve-market（测试版）

> 0.0.x 是测试版：功能还在陆续加入，配置项和命令的写法可能还会变。第一个正式版是 0.1.0。

EVE Online market helper for the official QQ bot, as a Koishi plugin (Tranquility server). It answers item price queries for the NPC trade hubs, configured markets and player structure markets (synced with one authorized service character through EVE SSO), appraises pasted lists and EFT fittings, draws price history charts, and searches items by Chinese or English name, pinyin or common slang. It also lists incursions, sends the influence maps, takes screenshots of battle reports, shows the server status and translates names between Chinese and English. It only replies on the official QQ platform (adapter-qq) and leaves other platforms such as OneBot alone. All replies are in Chinese.

EVE Online 欧服（Tranquility）市场助手，Koishi 插件，**只在 QQ 官方机器人上回复**。

- 群里先 @机器人 再输入；私聊直接发。
- 中文名、英文名、常用简称（黑话）、拼音都可以；有几个可能时会列出来让你点选，也可以 @机器人 回复编号。
- 管理命令只回应控制台「管理员」里的人（或 Koishi 权限等级 4 以上）；「市场状态」「市场授权」只在私聊或授权群里回应，「样式自检」在哪个群都行。别人发了没有反应，帮助里也看不到。
- 批量查价的物品名一律写中文（没有中文名的写英文），粘贴的是英文也一样。
- 命令后面跟着的图片和表情会被忽略，只看文字（游戏里复制的物品链接照常认）。命令后面只有图片时，会提示「图片里的字我看不到，请在游戏里复制后粘贴」；只发图片、没写字时不回复。
- 回复现在会引用你的那条消息，在群里还会 @ 你（QQ 不接受带引用或 @ 的消息时，去掉再发一次，之后这一类消息不再带，日志里写一次）；列表里的选项是可以点的文字，点一下把命令填进输入框，要再按发送。

## 制造、制造比价、反应

| 命令 | 例子 | 说明 |
|---|---|---|
| 制造 | `制造 乌鸦级` | 基础参考：材料成本、制造时间（蓝图 ME 0 / TE 0，不计建筑、改装件、星系成本指数和税）、主要材料、成品价格 |
| | `制造 乌鸦级 XX-1` | 在控制台配置的工业地点算：地点的默认建筑和改装件、默认 ME/TE、建筑的设施税，直接出结果（安装费用、设施税、SCC 附加费、总成本、利润） |
| | `制造 乌鸦级 XX-1 ME10 TE20 建筑:大厂 改装:默认 税:1%` | 参数都写上；`建筑:无` 不用建筑加成，`改装:无` 不用改装件 |
| | `制造 乌鸦级 高级` | 一步一步选：地点 → ME/TE → 建筑（只有一个选项的步骤自动跳过） |
| | `制造 乌鸦级 材料` | 材料清单，再单独发一条可以直接粘进游戏「多重购买」窗口的清单 |
| | `制造 帕拉丁级 XX-1 拆到原料` | 从月矿元素一路算到成品：先回一张总览卡，点按钮再看「分层明细」「原料清单」，见下面「拆到原料」 |
| 制造比价 | `制造比价 乌鸦级`、`制造比价 乌鸦级*10 ME8 TE16` | 本群能用的每个地点各算一次，按总成本排序，标出最便宜和最快的；加 `改装:无`、`税:1%` 时每个地点都这样算 |
| 反应 | `反应 富勒化合物`、`反应 富勒化合物 XX-1 20流程` | 反应的材料成本、时间和产出价值；没有 ME/TE，高安不能进行反应 |

- 没写 `建筑:` 时，同一个地点的每座建筑都算一遍，自动用预计总成本最低的（一样便宜挑更快的），卡片上写「自动选择：建筑名」；写了 `建筑:名称` 就照你写的用。
- 造不了这个产品的地点不列出来（例如万古级只有有超旗舰船坞的地点列得出来），卡片底下写「另有 N 个地点造不了（需要…）」；只剩一个地点能造时直接用它；命令里写了造不了的地点时，说明原因并给能造的地点按钮。
- 税分开设：每座建筑可以分别填制造税、反应税、提炼税。
- 数量写成 `乌鸦级*10`（产品数量，自动换算成流程数），或者 `10流程`。
- 结果卡片下面的按钮可以改 ME/TE、换地点、改建筑和改装件、改税率、看材料、比较地点；每个按钮里都是一条完整的命令。
- 「查价」的卡片上，有制造蓝图或反应配方的物品多一个「制造成本」按钮；不能在市场上交易的蓝图（例如 T2 蓝图）也有，按它的产品算。
- 「市场状态」里多一行星系成本指数和调整价的更新时间。
- 想慢慢调参数可以私聊机器人，不刷群。

### 拆到原料

`制造 帕拉丁级 XX-1 拆到原料`：把成品一层一层拆开（成品 ← 组件 ← 高级反应 ← 低级反应 ← 月矿元素、矿物等原料），每一层自己造或者直接买，算出总成本、利润和时间。

- 只回一张总览卡，下面的按钮：「分层明细」（每一层每一种东西需要多少、几批、多出多少、花多少）、「原料清单」（要买的原料，后面另发一条可以粘进「多重购买」的清单）、「继续拆」（把原来直接买的 T1 船体、R.A.M.、燃料块也拆开）、「反应:买」「组件:买」（把那一层改成直接买）、「换地点」、「只算成品」。点按钮是一条新命令，不占这次的回复条数。
- 每一层造还是买：控制台「工业」里设默认（反应、组件默认造，T1 船体、R.A.M.、燃料块默认买）；命令里写 `反应:买`、`组件:造`、`其他:造` 就改。写了其中任何一个，就等于写了「拆到原料」。
- 反应一批做多少是固定的，所以按整批算，多出来的在明细里写「多出 N 个」，成本不扣；需求很少、自己造比直接买贵 3 倍以上的那一层，总览卡会提示「量太少，整批造不划算」。组件蓝图按 ME 10 / TE 20 算，反应没有 ME/TE。
- 低级反应可以走**炼金术**（把「粗糙的…」产物提炼成反应产物）：`反应:炼金`、`反应:正常`、`反应:自动`（默认，挑便宜的），卡片上写出和正常路线差多少钱、多多少时间，并写明「提炼：建筑（地点）税 x%」。提炼率按「废料」规则：50% ×（1 + 2% × 废料处理技能等级），默认 5 级 = 55%。炼金出来的副产品先抵掉同种原料要买的数量，抵不完的写「多出 N 个」、不算钱。
- 命令里的 `税:1%` 只改成品这一步；组件、反应各用它们自己建筑的税。时间是每一层按一条生产线串行加起来的，不含技能，卡片上注明「多开可以更快」；比串行合计短时，还有一行「每种各开一条线同时做（一层做完再做下一层），最快约 X」（各层最长的一项加起来）。
- 命令写的地点没有精炼厂时，反应放在控制台设的默认反应地点（没设就用表里第一个能反应的地点），总览卡上写明。
- 价格一次取完，最多等 12 秒；没赶上的价格记为缺价格，结果标「不完整」。要拆的东西超过 200 种时直接说拆不了，可以加 `组件:买` 少拆几层。
- 「制造比价」不拆到原料，写了这些词会被忽略，并在卡片上注明。
- 发明成本不计入；炼金的规则（提炼税按 ISK 收、整批一次向下取整、废料处理 5 级 55%）已在游戏里核对（见 [docs/工业公式.md](docs/工业公式.md)）。

### 在控制台配置工业地点

打开本插件的设置，找到「工业」分组（每一项的说明和例子见 [docs/控制台配置.md](docs/控制台配置.md) 的「工业」一节）：

1. **工业地点**：一行一个地点。名称随便起（例如「XX-1」），别名用逗号分隔（例如「联盟工业点A」），星系填星系名或星系 ID。「谁能看到」选「只在授权群」时，其他群、私聊里不能用这个地点：发了它的名字会回「这里没有叫 XX-1 的工业地点」（和根本没有这个地点时一样，别的群看不出它存在），地点列表里也不会出现。勾一个「默认地点」，基础卡片上的「快速计算」就用它。
2. **工业建筑**：一行一座。「地点」填上面的地点名称；「名称」是命令里用的简称（例如「大厂」）；「建筑类型」填 Raitaru、Azbel、Sotiyo、Athanor、Tatara 等的名字（中英文都行）或 typeID，NPC 空间站填「NPC」，不要建筑加成填「无」；「改装件」填建筑上实际装的，名称或 typeID 用逗号分隔，插件自己判断哪个对这个产品生效；「制造税」「反应税」「提炼税」分别填建筑主人设的税率（反应税留空 = 和制造税一样，提炼税留空 = 0）；「有超旗舰船坞」只有索迪约能勾；「用途」可以选制造、反应、提炼和它们的组合；联盟另外收的钱填「其他费用」。
3. 建筑和改装件的加成数值来自物品数据，不用填。写错的行会被跳过，「市场状态」里会写明是哪一行、哪里不对（例如索迪约放在高安、改装件尺寸和建筑不符、高安或不是精炼厂的建筑做反应、建筑类型「无」勾了提炼）。停用的地点连同它的建筑一起不生效，不算写错。
4. 材料和成品默认按 Jita 出售价算，可以在「工业」分组里改成别的市场或价格类型；「回退市场」是材料没有价格时改用的市场（卡片上标 †）。
5. 拆到原料的默认设置（每一层造还是买、炼金、默认反应地点、提炼地点、废料处理技能等级）也在「工业」分组里，都有默认值，不填也能用。

星系成本指数和调整价来自 ESI（每小时更新一次，插件缓存，ESI 暂时取不到时用之前的数据，卡片上会写明）。公式、取整规则、还没核实的常量见 [docs/工业公式.md](docs/工业公式.md)。

## 官方机器人看门狗

adapter-qq 断网恢复以后，有时会一直拿过期的令牌去连（日志每分钟报「AccessToken无效或过期」），自己好不了，只能在控制台把它停用再启用。本插件替你盯着：官方机器人连续 10 分钟不在线，就自动重启 adapter-qq（和停用再启用一样），两次至少隔 30 分钟。

- 默认打开，控制台「基本」里的 `qqWatchdog` 可以关。
- 只重启 adapter-qq，不碰 LLBot 和转发。
- 每次重启都写进 Koishi 日志；管理员发「市场状态」，「官方机器人」一行能看到在不在线、自动重启过几次。

## 走势图和网站截图（puppeteer）

走势图和网站截图（战报、Janice、DOTLAN 等）要用 Koishi 的 **puppeteer** 插件（插件市场里搜 `puppeteer`，Koishi 官方的那个）。它是可选的：

- 没有装、或者没有启用时，「走势」只发文字卡片，卡片里有一行文字走势（`走势 ▁▂▃▄▅▆▇█…`）；「战报」「截图」回复「截图服务没有启动，请联系管理员。」，Koishi 日志里也会写一句。
- 以后再装也行：插件每次出图时才去找 puppeteer，装好、启用以后马上就能用，不用重启本插件。
- 走势图里的中文要用系统里的中文字体（Windows 自带的微软雅黑就可以）。Linux 服务器上如果图里的中文是方块，要先装一个中文字体（例如文泉驿或 Noto Sans CJK）。
- 浏览器页面最多同时开 2 个（网站截图最多占 1 个，所有网站排同一个队），每次用完就关；截图慢时（超过 3 秒）会先发一句「⏳ 正在…」。
- 同一个市场、同一个时间范围的走势图，在成交历史更新（一般一天一次）、日期变化（按 EVE 时间）之前再要直接用缓存；同一个截图链接 10 分钟内再发也直接用缓存。

网站截图的自动识别：群里 @机器人 的消息、或者私聊消息里带名单里网站的链接时，插件自动截图（每条消息只处理第一个能截的链接，回复里不会再写出链接）。名单里自带 BR 工具战报、Warbeacon 战报、Janice 估价结果、DOTLAN 星图四个网站，另外可以在控制台「截图」里加自定义网站（最多 10 个）；每个网站可以单独关掉，或者只关自动截图。不想要的话，在控制台「截图」里关掉对应网站的「自动截图」，之后只有写明「截图 网址」才截；「战报 链接」只认战报网站。

安全：只打开名单里的域名，一律用 https；页面跳到名单外的域名就放弃，页面里对本机和内网地址的请求一律拦下；网站弹出人机验证页时回复「这个网站不让自动截图」，不绕过。不支持截 zKillboard 的页面（击杀链接用「击杀」命令）、要登录的页面、IP 地址和带端口的网址。页面弹出的新窗口会被关掉，不算失败。Warbeacon 只认关联战报和单场战报页，Janice 认估价结果页；各网站的页面参数还没在生产机上核对，见 [测试步骤](docs/测试步骤.md)。旧设置 `render.brAuto` 还在，关着时 BR 工具战报一律不自动截图，升级前看一眼；详见 [控制台配置](docs/控制台配置.md)「截图」一节。

势力图从 Verite 下载，本机缓存 60 分钟；Verite 暂时访问不了时发缓存里的旧图。图片地址在控制台「图片与截图」里可以改，留空就关闭这个命令。

## 上线前：样式自检

QQ 客户端对 Markdown、按钮、图片的显示有些地方没有文档写明。机器人在测试群里能用以后，管理员 @机器人 发「样式自检 1」，看完再发「样式自检 2」：

- 每条测试消息开头都写了「正常」是什么样子，照着看就行；
- 第 1 页最后一条、第 2 页最后一条写了回报的格式，照这个格式把结果告诉开发者；
- 有不正常的地方，开发者改好以后发一个补丁版本，控制台里不用改任何设置。

## 联盟建筑市场（EVE 授权）

玩家建筑里的订单只有能停靠的角色才能看到。用一个能停靠的角色（服务角色）授权一次，插件就会每隔几分钟把整个建筑市场同步下来：

- 只有控制台「授权群」里的群能看到建筑市场的价格，其他群照样能查 Jita 等公开市场（和这个市场不存在一样）。
- 授权或停靠权限出问题时，这个市场显示「市场数据暂时不可用（ESI 授权或建筑访问权限异常）」，不显示旧价格；同一条回复里的其他市场照常。
- 授权在浏览器里做：控制台本插件设置页最上面的「打开 EVE 授权页面」。页面只接受在 Koishi 所在电脑上直接打开（经 SSH 隧道也算，经反向代理、内网穿透转发的不算；这台电脑上有反向代理或内网穿透时一定要设「授权页面的口令」），可以按名字搜建筑、直接给出要填进「市场」表格的那一行。
- 刷新令牌加密保存在数据库里，密钥是单独的文件 `data/eve-market/secret.key`；**换电脑时把它和数据库一起带走**。页面、QQ 消息和日志里都不会出现令牌和 Secret Key。

一步一步的做法（创建 EVE 应用、勾哪些权限、回调地址怎么填、重新授权、常见问题）见 [docs/EVE授权.md](docs/EVE授权.md)。

## 安装

第一次装，请按下面「[文档](#文档)」一节的顺序做，这里只列要点。

1. 挑群里没人说话的时候，打开 Koishi 控制台的「插件市场」，搜索 `koishi-plugin-eve-market`，**确认作者是 yilifaer**，点安装。装好以后，在「插件配置」页面点右上角的插头图标「添加插件」，搜 `eve-market` 把它加进来（只安装的话，插件配置里没有它）。
2. 插件需要 `database`（任意一种数据库插件，例如 database-sqlite）和 `http` 服务（Koishi 自带）；EVE 授权页面还要用 `server` 服务（Koishi 控制台本身就用它，一般都有）；走势图和网站截图要用 `puppeteer` 服务（可选，见上面一节）。
3. QQ 官方机器人用的是 adapter-qq；本插件不碰其他平台（例如 LLBot 的 OneBot）上的消息。
4. 启用插件，先看一眼配置里的「市场」表格：预置了 Jita 和另外四个 NPC 交易中心，可以改、删、加。
5. **启用 adapter-qq 之前**，先给只在 LLBot 上用的插件（包括旧的查价插件）设过滤器「平台 等于 onebot」，否则它们也会经官方机器人回答。做法见 [docs/从旧插件迁移.md](docs/从旧插件迁移.md) 第 2 步。然后按 [docs/QQ机器人注册.md](docs/QQ机器人注册.md) 第 6–7 步填好 adapter-qq、启用。
6. 在群里 @机器人 发「本群ID」，把群 ID 填进「授权群」，把你的 ID 填进「管理员」（群里和私聊里拿到的 ID 可能不一样，都填上；见 [docs/控制台配置.md](docs/控制台配置.md) 的「权限」）。
7. 有联盟建筑市场的话，按 [docs/EVE授权.md](docs/EVE授权.md) 做一次 EVE 授权，然后以管理员身份发「市场状态」确认。
8. 在测试群里做一次「样式自检」（见上面一节）。

升级：先在「依赖管理」页面右上角点一下「刷新」，否则版本列表可能还显示旧版本（用 npmmirror 这类镜像时尤其常见）；然后在插件市场里点更新。回滚：「依赖管理」里选回上一个版本。注意：安装、升级、卸载插件都会让整个 Koishi 重启一次（转发断大约 20 秒），挑群里没人说话的时候做。

配置写错的行会被跳过（插件照常加载），Koishi 日志和「市场状态」里会写明是哪一行、哪里不对。

## 数据从哪里来

- 物品、工业、星图数据：由 [eve-cn-slang](https://github.com/yilifaer/eve-cn-slang) 每周从 CCP 发布的静态数据（SDE）生成。插件启动后在线检查更新；下载不了时用本地缓存，再不行用包里自带的快照。
- 价格：EVE 的 ESI 接口（欧服），遵守 ESI 给的缓存时间和限流。联盟建筑市场用服务角色的 EVE 授权读取（EVE SSO），整站同步后存在本机缓存里，重启后不会在 ESI 过期之前重新请求。
- 简称、黑话：EVE Online 中文黑话表（同一个仓库的 `glossary.yaml`）。
- 走势：ESI 的星域成交历史（每天更新一次）；入侵、服务器状态：ESI。
- 势力图、联盟势力图：[Verite](https://www.verite.space/) 的图片，原样转发。
- 网站截图：只打开名单里网站的地址。自带 [BR 工具](https://br.evetools.org/)、Warbeacon、Janice、DOTLAN，以及控制台里加的自定义网站。
